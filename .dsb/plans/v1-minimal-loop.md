# V1 最小闭环实现计划：点云 → 单件 B-rep

> 依据：《整体框架》第十一章（V1 实现路线与执行要点，表 43/51）+《拓扑同胚》第六章（工业逆向 CAD 闭环）。
> 目标：用**三级递进样本 S1/S2/S3**手工打通端到端链路，标定每环阈值，产出可导出的 B-rep / STEP。
> 原则：V1 **不追求自动化**，一切以「跑通 + 可标定 + 可评测」为准；DL 环节暂由人工/半自动替代。

---

## 〇、V1 三级样本设计（对齐《框架》11.1.2 表 43）

由易到难，每级都可手工核验；**S2 是核心样本**。

| 级别 | 样本 | 覆盖环节 | 为什么这样设计 |
|---|---|---|---|
| **S1** | 单个长方体，**故意遮挡全部顶点与棱**（每个面只拍中间一块） | 面拟合、顶点求解、半空间筛选、定向传播、欧拉检查 | 最纯粹的骨架验证：**顶点处零观测，若能重建出 8 顶点 / 12 边 / 6 面，即证明「演绎优于插值」** |
| **S2** | 带孔板 + 4 个螺钉，**仅从螺钉头一侧扫描** | 完全不可见面、部分缺失面、标准件匹配、配合关系、干涉回检、语义—几何冲突 | 覆盖主线全部环节；逼出「**螺钉存在 ⟹ 板必须有孔，但点云上看不到孔**」这一冲突 |
| **S3** | 含**倒角 / 圆角 / 相切**过渡的零件 | 边界性质判定（5.4.2 三分支判据）、退化情形兜底 | 检验 5.4.6 的 fallback 是否成立 |

> **样本获取方式**：S1 用合成（点云与真值同出一套 CAD 内核，误差归因干净）；S2/S3 用公司 3D 相机 + 机器人实拍（扫描精度约 **0.5 mm**，见第四节特征尺度约束）。
> **实物建议**：S2 直接采用标准件（如内六角圆柱头螺钉 1/4″-20 一类成熟件号），CAD 真值可从厂商库下载 STEP。厂商库多为**无螺纹简化模型**——本框架中通常有利（螺纹属 L2 细节层，不入 L0 基形）。

## 一、V1 范围界定

### 做什么
- 单零件（非装配体），刚体、无自由曲面（或仅少量圆柱/球）。
- 输入：已知位姿的多视角稠密点云（或直接由 CAD 采样的理想点云起步）。
- 输出：**单件 B-rep**（平面 + 柱/球等解析面），可导出 STEP AP242；附 provenance 与不确定性 JSON。

### 明确不做（留给 V2 及以后）
- 装配级多体求解、约束传播、TMS 非单调回溯。
- 完全不可见面 / 部分缺失面的语义补全。
- 主动补拍闭环（规划 → 补拍 → 重算）。
- 端到端 DL 分割（V1 用人工/几何法分片，V2 再替换）。

## 二、V1 流水线（8 步，对应 P0—P8 的裁剪版）

| 步 | 名称 | 输入 | 输出 | 范式 |
|---|---|---|---|---|
| S1 | 预处理 | 原始点云 | 去离群、法向一致、体素下采样、法向估计 | 传统 |
| S2 | 分片 + 类型 | 干净点云 | 逐点 mask + 基元类型（V1 人工/AABB 启发式；V2 DL） | 人工→DL |
| S3 | 拟合 + 残差判据 | 每片点集 | 基元参数 + 鲁棒残差（Huber/95 分位） | 传统 |
| S4 | 残差诊断 → 处置 | 残差分布 | 分片 / 换类型 / 回预处理 三分支决策 | 规则 |
| S5 | MDL 停止 + 合并 | 分片序列 | 防过分割的稳定分片集 | 传统 |
| S6 | 全局正则优化 | 独立拟合的基元 | 平行/垂直/共轴/等半径/对称一致的基元 | 传统(GlobFit) |
| S7 | 边界双向调整 + 拓扑 | 基元 + 点云 | 有界 face/edge/vertex + 环 | 传统 + 解析 |
| S8 | 验证 + 导出 | 拓扑 | 欧拉校验通过 + STEP AP242 + 元数据 JSON | 传统 |

## 三、模块与文件规划（建议目录）

```
src/
├── io/            # S1: 点云读取、下采样、法向估计 (Open3D)
├── segment/       # S2: 分片与类型推荐（V1 人工切面；接口预留给 DL 头）
├── fit/           # S3: 平面/圆柱/球的最小二乘 + RANSAC 精修
├── diagnose/      # S4: 残差统计（Huber RMS、分位数）+ 三分支决策规则
├── mdl/           # S5: MDL 代价（L_residual + L_model）+ 停止/合并准则
├── regopt/        # S6: GlobFit 风格全局约束优化
├── topology/      # S7: 参数域投影+包络、面面求交、裁剪、顶点/边/环
├── verify/        # S8: 欧拉公式 V−E+F−L=2(S−G)、自由边检测
├── export/        # S8: OCCT B-rep 构建 + STEP AP242 写 + JSON provenance
└── eval/          # 评测：端到端有效性 + 失败案例集
tests/             # 每个模块的最小单元测试（TDD 优先）
```

**核心依赖**：Open3D（IO/预处理）、NumPy/SciPy（拟合/优化）、OpenCASCADE（OCCT，B-rep 构建与导出）、CERES 或 SciPy least_squares（全局正则）。MDL 与 GlobFit 需自研，是最大工作量。

## 四、关键实现要点（逐模块）

### S3 拟合与残差
- 距离度量：平面 `|n·p+d|`、圆柱 `|dist(p,axis)−r|`、球 `|‖p−c‖−r|`。
- **真实扫描禁止用朴素 RMS**（飞点会拉爆，好基元被误判）→ 用 Huber/Tukey 核或 95 分位距离。

### S4 残差诊断（三分支判据，务必分开）
- 残差**集中在区域一侧** → 真是多个基元 → 重新分片。
- 残差**均匀分布 + 系统性曲率** → 类型选错 → 换类型（勿分片，否则自由曲被切成碎片）。
- 残差**零星 + 伴飞点** → 点云有问题 → 回退预处理。

### S5 MDL
- 目标函数：`MDL = L(residual) + L(model)`；仅当新增基元的残差下降 > 增加模型的代价时才继续分片。
- 权重/阈值对传感器噪声极敏感 → 需在典型零件上标定并记录。

### S6 全局正则
- 先独立拟合得初值 → 检测两两基元的平行/垂直/共轴/等半径/对称 → 硬/软约束全局最小二乘，同时调整全部基元。
- **利用设计意图**（「平行就是平行」），这是精度跃迁的关键。

### S7 边界双向调整（方向不可混）
- **方向 A（点云 → 定「取哪一段」）**：无限交线由两面点云覆盖范围共同裁剪，点云只做**存在性判定**。
- **方向 B（理论 → 定「精确形状」）**：用解析交线（直线/圆弧）替换锯齿边界。
- 参数域：平面→2D、圆柱→θ-z 矩形、球→θ-φ。
- **两陷阱**：① 自由边（无相邻面）没有理论交线，只能靠点云 + 直线/圆弧拟合，方向 A/B 公式只对非自由边成立；② 真实边界是自由曲线（自由曲面相交、圆角过渡）时**不可硬拉直** → 按类型 head 结果选曲线类型（平∩平→直线、平∩柱→圆、柱∩柱→空间曲线、含自由曲→样条兜底）。

### S8 验证
- 欧拉公式：**V − E + F − L = 2(S − G)**；不通过 → 拓扑有洞或碎面。
- 自由边检测：仅允许出现在真实开口处。

## 五、阈值标定清单（V1 的核心产出之一）

| 参数 | 含义 | 标定方法 | 依赖 |
|---|---|---|---|
| ε_fit | 单基元拟合接受阈值 | 典型零件上人工确认 | **尺度相关**，先固定尺度 |
| ε_merge | 合并判据（平面夹角/距差；圆柱轴角/半径差/共线） | 过分割/欠分割平衡 | 尺度相关 |
| τ_MDL | MDL 模型复杂度权重 | 过分割临界点扫描 | 噪声相关 |
| 正则容差 | 平行/垂直/共轴的判定容差 | 设计意图 + 公差 | 尺度相关 |
| ε_eval | 端到端合格判据 | 与 GT 比对 | 尺度相关 |

> 深水区提示：所有 ε 都**尺度相关**（约束本身尺度无关），须先统一尺度体系再定死阈值。

## 五之二、特征尺度下限（由扫描精度决定，V1 硬约束）

> **为什么写在这里**：S3 要判「倒角 / 圆角 / 相切」。这类判据靠**法向变化**，而法向估计精度受限于**特征带宽**。若特征本身小到传感器测不出，S3 失败属**传感器物理极限**，与算法无关——必须事先划清这条线，否则会误判算法。

**设备基线**：公司 3D 成像相机 + 机器人，扫描精度约 **σ = 0.5 mm**。

**三条判据（分开列，不可混用）**：

| 判据 | 表达 | 含义 |
|---|---|---|
| **A. 法向估计** | θ ≈ 2√2·σ / (R√N) | 噪声主导；面片越大、点越多，法向越准（**与特征尺度无关**） |
| **B. 采样带宽** | W_min = k·spacing | 特征带宽上至少落 k 个点（k 取 3—5） |
| **C. 特征可分辨** | W_min = (SNR·8√2·σ·√spacing / π)^(2/3) | 圆角 90° 弧的法向变化量须大于噪声，SNR≥5 可识别、≥10 稳健 |

**实算结果（σ=0.5 mm，spacing=0.2 mm）**：

| 项 | 数值 |
|---|---|
| 面【位置】精度 | ≈ σ/√N，N=2000 → **11.2 µm**（远超 0.5 mm，印证「演绎优于插值」） |
| 面【法向】1.0° 预算所需最小面片半径 | N=2000 → **R_min = 1.81 mm** |
| 采样带宽下限 | **W ≥ 1.00 mm** |
| 圆角可分辨半径 | **r ≥ 1.61 mm**（SNR≥5）；**r ≥ 2.56 mm**（SNR≥10 稳健） |
| **V1 样本特征尺度建议** | **≥ 2.6 mm**；**低于 1.6 mm 预期失败**（传感器极限，非算法缺陷） |

**对 V1 的具体约束**：
1. **S3 样本**的倒角宽度 / 圆角半径 **必须 ≥ 2.6 mm**；若选用 < 1.6 mm 特征，须在失败案例集中标注为「已知不可测」，不计入算法失败。
2. **S1 长方体**尺寸应 ≥ 20 mm（保证各面片 R ≥ 10 mm，法向误差 < 0.2°）。
3. **S2 的孔 / 螺钉**：孔径 ≥ 4 mm（带宽足够），M3 以下小孔须预期拟合不稳。
4. **ε 的物理下限**：`ε_fit` 不得小于拟合统计波动，否则必然过分割（脚本可给出该下限）。

**推算工具**（改了 σ / spacing 直接重算）：
```bat
chcp 65001
python src\tools\min_feature_scale.py --sigma 0.5 --spacing 0.2
python src\tools\min_feature_scale.py --sigma 0.5 --spacing 0.2 --verify
```
> `--verify` 用蒙特卡洛核对判据 A 的解析近似（两者同量级即认为可用）。

## 七、验证与评测（对齐《框架》第九/十一章）

- **端到端优先于模块指标**：唯一有意义的对比是「完整流水线 + 同批真实样本」。
- **失败案例集跨版本累积**：判断改进是否真的有效。
- 指标建议：面/边数量与 GT 的匹配、解析参数误差、拓扑合法性（欧拉/水密）、下游可用性（能否装配/干涉检查）。

## 八、风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 过分割 | B-rep 碎面、拓扑非法 | MDL + 合并（S5） |
| 残差阈值定不住 | 好基元被误判/坏基元被接受 | 鲁棒核 + 尺度统一 + 标定清单 |
| 自由边处理 | 边界错误 | 仅对非自由边用理论修正；否则点云拟合 |
| 自由曲线被硬拉直 | 过度修正 | 按类型判边类型，样条兜底 |
| sim-to-real gap | 真实数据崩溃 | V1 先理想数据，M6 引入真实数据并记录失败 |

## 九、V1 → V2 演进（预告，不在 V1 范围）

1. 用 DL 逐点分割头 + 基元类型头替换 S2 的人工分片（保持「模型只输出决策、参数由解析算」）。
2. 引入 latent 几何理解：ShapeVAE 冻结 encoder + 线性探针（平面vs曲面 / 开口vs封闭 / 尺寸回归）；用 decoder SDF 做微分几何读基元（无需重训）。
3. 逐步加入装配级约束传播、TMS 非单调回溯、主动补拍闭环。
