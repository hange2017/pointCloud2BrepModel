# `src/` — 项目源码与工具脚本

> 状态：**骨架已建，实现待环境就绪后填充**（见 `.dsb/specs/` 设计说明与 `.dsb/plans/v1-minimal-loop.md`）。
> 约定：本目录为纯 Python 包；不含数据与产物（点云 / STEP / 权重均在 `.gitignore` 中排除）。

## 目录规划（对齐 V1 八步流水线 S1—S8）

```
src/
├── io/            # S1 预处理：点云读取、体素下采样、法向估计（Open3D）
├── segment/       # S2 分片 + 基元类型（V1 人工/启发式；接口预留 DL 头）
├── fit/           # S3 平面/圆柱/球拟合 + 鲁棒残差（RANSAC + 最小二乘）
├── diagnose/      # S4 残差诊断三分支（细分 / 换类型 / 回预处理）
├── mdl/           # S5 MDL 代价与停止/合并准则
├── regopt/        # S6 GlobFit 全局正则优化
├── topology/      # S7 边界双向调整 + 面面求交 + 顶点/边/环
├── verify/        # S8 欧拉校验 V−E+F−L=2(S−G) + 自由边检测
├── export/        # S8 OCCT 构建 B-rep + STEP AP242 + provenance JSON
├── eval/          # 评测：端到端有效性 + 失败案例集
├── synth/         # 合成数据：CAD 真值 + 遮挡生成（S1/S2/S3 样本）
└── tools/         # 独立分析脚本（不参与主流水线）
```

## 设计原则（框架约束，写代码时不可违背）

1. **模型只输出决策**（类型 / 分割 / 边界性质 / 候选）；**几何参数一律由解析拟合算出**。
2. **不从网格提取边**：边由面面解析求交（SSI）得到，避免 zig-zag。
3. **精度锚点在符号端**：SSI / 裁剪 / GlobFit / 欧拉校验是精度分水岭。
4. **尺度先行**：所有 `ε` 尺度相关，先统一尺度体系再定阈值。
