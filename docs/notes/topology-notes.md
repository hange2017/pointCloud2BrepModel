## 第一章　拓扑等价：5 面开口盒子与开口半球

### 1.1 二者都是「圆盘（disk）」

正方体去掉上表面后的开口空腔（曲面网格：8 顶点 / 12 边 / 5 面）：

- 欧拉示性数 χ = V − E + F = 8 − 12 + 5 = **1**
- 顶部原被上表面共享的 4 条边退化为**边界边**，构成一个正方形边界环 → 边界分支数 b = 1
- 带边界可定向曲面分类公式：χ = 2 − 2g − b → 代入 χ=1、b=1 → **亏格 g = 0**

开口半球（碗）：边界为赤道圆，三角化后同样 χ=1、b=1、g=0。

**结论**：二者拓扑上完全等价——连通、可定向、亏格 0、带 1 个边界环 = **圆盘 D²**，可经连续拉伸/弯曲互转（不需撕裂或粘合）。同理，平板、帽子、碗、没盖的纸盒拓扑上都是同一个东西。

### 1.2 澄清一：它不是拓扑学意义上的「洞（handle）」

- **开口凹槽 / 碗 / 盲孔**：亏格 = 0，**不产生拓扑洞**。无论多深多大，只要开口（与外界连通），拓扑上仍是一张 disk。
- **真正的拓扑洞**：贯通的隧道。立方体上下打穿方孔 → 曲面变环面（torus），g = 1，χ = 0。
- **封闭空腔（void）**：完全包在实体内部、不与外界连通 → 实体边界多出一个独立封闭球面分支。

### 1.3 澄清二：凹凸不是拓扑性质，而是几何/嵌入性质

纯拓扑层面凹腔与凸半球无法区分（碗翻过来就是帽子，曲面仍是 disk）。但带上「材质在曲面哪一侧」的语义后完全不同：

| 维度 | 开口立方体空腔（pocket） | 外凸半球（boss） |
|---|---|---|
| 材质位置 | 曲面外侧，向内凹 | 曲面内侧，向外凸 |
| 法向 | 指向空腔中心（朝内） | 朝外 |
| CAD 语义 | **减材特征** | **增材特征** |
| 制造方式 | 铣削、开槽 | 铸造凸起、3D 打印加料 |

→ B-rep / 特征识别中「凹槽」与「凸台」必须分开，原因是**凹凸（法向朝向）不同**，而非拓扑不同。

### 1.4 澄清三：开口凹槽（pocket）vs 封闭空腔（void）

- **开口凹槽**：实体本身仍是拓扑实心球（3-ball），只是边界一部分被往里按了个坑，边界整体仍是一个球面 S²。
- **封闭 void**：如方块内部封闭球形气泡 → 边界分成两个互不连通分支（外表球面 + 内表球面），这才是「真的多了一个内部空腔」。

本文档讨论的「没有上表面」属第一种。

### 1.5 对网格分割的意义：拓扑等价 ≠ 分割/基元等价

| 维度 | 5 面开口盒子 | 开口半球（碗） |
|---|---|---|
| 基元类型 | 5 个平面 | 1 个球面 |
| 高斯曲率 | 面上处处 0（可展） | 处处 1/R²（常正曲率，不可展） |
| 棱边 | 8 条明显棱边（二面角 90°） | 光滑无棱边，曲率连续 |
| RANSAC | 拟合 5 平面 + 检测棱边 | 只拟合 1 个球面 |
| 区域生长 | 按「法向一致 + 零曲率」分 5 区 | 整碗一区，或按方向细分 |

**结论**：拓扑分类任务中它们等价；**部件分割 / 基元拟合 / 曲率聚类**任务中完全不等价——方形凹槽被拆成几个平面，半球凹坑只能拟合成球面，算法路径完全不同。

## 第二章　同胚能否用算法实现变形？

### 2.1 同胚只保证「存在」，算法负责构造「好看」的路径

同胚只保证连续双射存在，不保证路径可用（可以是极度扭曲的映射）。算法目标是构造**低扭曲、保特征、无自交、视觉自然**的变形路径（同伦 homotopy / 形状插值 morphing）。变形路径不唯一（保角 / 保面积 / 保刚性 ARAP 的中间态完全不同），算法要做的是**选择一条美学与工程都合适的路径**。

### 2.2 路线一：隐式场 / SDF 插值（零对应成本）

φt(x) = (1−t)·φA(x) + t·φB(x)，每个 t 用 Marching Cubes 提取零等值面。

- **优点**：不需要顶点对应（最大优势）；天然处理外观差异大的形状；中间态拓扑可自然变化。
- **坑**：线性插值后 SDF 不再是精确距离场（|∇d| ≠ 1），等值面畸变，需 re-initialization；远距离特征会「糊」；薄壁中间态易断开。

### 2.3 路线二：Latent 空间插值（现代主流）

zA、zB 插值得 zt 再解码（机制见第三章）。

### 2.4 路线三：网格参数化 + 对应 + ARAP（最可控）

大前提是**必须先建立对应关系**（最难一步）。对应方法：共形/调和参数化到公共域 + Möbius 对齐；Landmark + TPS/RBF；Functional Maps；深度学习对应。

| 插值策略 | 做法 | 效果 |
|---|---|---|
| 顶点线性插值 | (1−t)pA + t·pB | 塌缩/扭曲（candy-wrapper），细节丢失 |
| **ARAP** | 逐三角面插值旋转（四元数 slerp）+ 缩放，最小二乘重建顶点 | **保局部刚性，不塌缩，最常用** |
| Laplacian/微分坐标 | 插值微分坐标再重建 | 保局部细节，抗扭曲 |
| 共形/保面积 | 参数域上做保角/保面积插值 | 控制面积/角度扭曲 |

ARAP 是 morphing 事实标准，难点是大变形中间态可能自交（需防自交约束），且**要求拓扑同胚**。

### 2.5 形状不同胚（如球 → 甜甜圈）怎么办

- **网格法做不到**：拓扑变了无同胚变形，须先**拓扑手术**（cut graph 切成 disk → 参数化插值 → 按目标拓扑缝合）。
- **隐式场 / level set 天然可以**：等值面拓扑随 level 自动变化（可能在某个 t「长出把手」变环面）。这正是拓扑优化 / 活动轮廓 / 形状演化几乎都用 level set 的原因。

### 2.6 三路线对比与「盒腔 ↔ 碗」表现

| 路线 | 棱角变化 | 是否需要对应 |
|---|---|---|
| SDF 插值 | 棱角平滑消失，曲率连续化（场插值特性） | 否 |
| Latent 插值 | 视模型，通常自然（可能理解为语义渐变） | 否 |
| 网格 ARAP | **棱角保持锐利更久，最后才圆滑** | 是 |

有趣现象：盒腔「5 个平面区域」要对应碗的「单张球面」是对对应关系的考验；对应不好（如底面全挤到碗一小块）→ 中间态明显拉扯与自交。

## 第三章　Latent 空间插值深挖

### 3.1 插值发生在哪个 latent 空间（以 Hunyuan3D 为例）

| 空间 | 来源 | 能否插值 |
|---|---|---|
| **ShapeVAE 的 latent token（Zs）** | VAE encoder 压出的 token 串 | **能，插值就发生在这里** |
| DiT 内部去噪特征 / 流匹配轨迹 | 扩散去噪中间特征 | 一般不在那插值（那是生成过程） |

流程：Encoder 编码 A→zA、B→zB → 在 z 空间插值得 zt → Decoder（Point Perceiver → SDF → Marching Cubes）得中间形状。**插值这步 DiT/流匹配可完全不参与**（DiT 是「从文本/图像生成 z」，插值是「把已有两个 z 连起来」）。

### 3.2 KL 正则与流匹配的分工（重要纠正）

常见说法「KL 正则 + 流匹配去噪强制成平滑流形」方向对但需拆开：

- **KL 正则（+ 连续解码器）= latent 可插值的根本原因**：KL 把 latent 拉向后验（近似高斯），使空间填满无大空洞；解码器 D(z) 连续 → z 微变导致形状连续变。这是经典 VAE/GAN latent 漫步基础，**与扩散/流匹配无关**。
- **流匹配 / DiT 的额外价值**：在 latent 空间学速度场 vθ(zt,t)。① 能生成新 z（不只插值已有）；② 学到概率密度结构——沿 ODE 路径走比直线更不易掉进低密度区，中间态更保真。

**准确说法**：latent 插值本身靠 KL + 连续解码器；流匹配让「怎么在两个 latent 之间走」有更聪明的路径（沿概率流）。

### 3.3 为什么「性感」：摊销了对应成本

| 对比项 | 传统 ARAP / 参数化 | Latent 插值 |
|---|---|---|
| 每处理一对新形状 | 必须重建对应（慢且脆） | 直接 encode→插值→decode，**零对应** |
| 一次性成本 | 低 | 高（需训一个 shape autoencoder） |
| 总成本随形状对数量 | 线性增长 | 几乎不增长 |

一旦有 encoder，盒腔→碗、碗→飞机、杯子→椅子都是同一套流程。

### 3.4 三个隐藏前提

1. **需要能编好两个形状的 encoder**：OOD 形状的 z 本身失真 → 插值是「两个失真形状的糊化平均」，看着像 morph 其实细节全丢。传统 ARAP 至少忠实于你给的两个网格。
2. **插值路径不是只有直线**：高维中线性中点可能远离数据流形。三种走法：

| 走法 | 说明 | 保真度 |
|---|---|---|
| 线性插值 | zt = (1−t)zA + t·zB | 可能掉出流形，最朴素 |
| slerp（球面插值） | 归一化到球面走弧线 | 较好（StyleGAN 时代已验证） |
| 沿流匹配 ODE | 用速度场积分，每步在高密度区 | 最好，需 DiT/flow |

3. **中间态是「统计合理」而非「工程合理」**：不保证公差、不保证平面还是平面、不保证薄壁不断。→ 概念设计 / 动画 / 数据增强 → latent 完胜；精密逆向 / 工业检测 / 保特征 CNC → ARAP 更可控。

### 3.5 与 Hunyuan3D 链路的闭环

ShapeVAE 的 encoder 把 mesh/点云映射为 z（插值发生处），decoder 经 Point Perceiver → SDF → Marching Cubes 得 mesh。三种走法（线性 → slerp → 沿流匹配 ODE）从笨到聪明；DiT 流匹配正好提供第三种走法的「地图」。→ 这条路不是「与 DiT 无关」，而是**用 DiT 学到的速度场在 latent 流形上走出更聪明的 morph 路径**。

## 第四章　Latent token 能否做几何与部件理解？

### 4.1 latent 里到底有什么

能插值并解码连续 morph，即证明 latent 是**连续平滑的形状流形**，必然编码了几何——否则重建不出来。但它是**分布式、非解耦**的：编码的是重建所需信息，而非为人准备的语义/几何属性；对重建无用的属性（绝对物理尺寸、材料、建模历史）可能被直接丢掉。

| 常见误解 | 实际情况 |
|---|---|
| 「这里有 5 个平面，法向分别…」 | 一堆高维向量，长度/曲率/布局混在一起 |
| 显式符号 / 参数化 CAD | 分布式连续编码（形状的隐变量坐标） |
| 人能直接读 | 机器内部表示，必须「读出来」 |

### 4.2 两种「部件」必须分清

- **语义部件理解**（瓶盖/椅腿/机翼）：latent 单独做不到 zero-shot；可加 head（ShapeNetPart / PartNet / COSEG 上冻结 encoder 训分割头 = probing，或端到端微调）；zero-shot 需借 2D 视觉语言模型（多视角渲染 → SAM/CLIP 伪标签 → 反投影）或原生 3D 部件模型（P3-SAM、PartField、PartSLIP）。难点：依赖类别先验与人工标注，跨类别泛化难。
- **几何基元区域理解**（平面/柱面/凹腔/凸台）：与「仅局限几何理解」的需求最贴合，**可行性高得多**。关键优势是**标签可全自动生成**（程序化 CAD 生成「立方体挖方槽」时天然知道每点属平面/曲面、凹凸、尺寸）。代表工作：SPFN、HPNet、ParseNet（基元拟合/分割）；ComplexGen、Point2CAD（B-rep/CAD 逆向）；BSP-Net、CSGNet、UCSG-Net（布尔/CSG 树）。

### 4.3 五项几何理解逐项判断

| 几何理解目标 | latent 能否直接给 | 原因 / 坑 | 推荐做法 |
|---|---|---|---|
| 平面 vs 曲面（逐点基元类型） | **强，基本可以** | 曲率是低层几何，重建必须保留 | 冻结 encoder 训线性/MLP 探针；更好是微调逐点分割头 |
| 曲面类型 + 参数（柱/球/自由曲） | 类型可分，精确参数需 refine | 半径/轴向可能被纠缠；绝对尺度常被归一化 | 网络预测初始参数 → 对分割点做 RANSAC/最小二乘精修（Hybrid） |
| 大小 / 尺寸 | 常被归一化掉 | 训练常缩到单位球，latent 无绝对尺度 | 训练不归一化；加 scale token/OBB 回归头；或解码后从网格量 |
| 封闭（水密）vs 开口 | 取决于训练数据 | 若只在水密网格上训练，decoder 总会把开口补上 | 训练数据含开口/封闭并监督；或用重建误差做异常检测 |
| 曲面间相对位置/拓扑关系 | 单全局 latent 不够显式 | 全局 token「一锅炖」，无实例/槽位，邻接/对称/距离被纠缠 | slot attention / part token 先得实例，再建关系图/CSG 布尔树 |

其他有戏的属性：法向（∇SDF）、曲率（Hessian）、凹凸（法向朝向 + 曲率符号 + 局部 SDF 符号）、体积/表面积（MC 后积分）、OBB（PCA/凸包/RANSAC）、对称性（需专门监督或等变探测）。

### 4.4 「编码器 + 一些东西」= 几何解析模型

输入点云/网格 → Encoder（ShapeVAE/PointTransformer/DGCNN）→ 全局 latent z + 逐点/局部特征 F → 多个 head：
- **逐点基元分割头**：F → 平面/圆柱/球面/自由曲 + 初始参数
- **部件实例头**（Slot Attention/cross-attention）：z + F → part mask
- **全局属性头**：z → 是否封闭？尺寸/OBB？对称性？
- **关系头**（GNN on part tokens）：→ 相对位姿、邻接、包含、布尔树

之后可选 **Hybrid 精修**（RANSAC 拟合平面/圆柱、算 OBB、检测开口、量公差）——传统拟合功底比纯网络更准。

学术名字：基元拟合网络（SPFN/HPNet/ParseNet）、部件分割（PointNet++/Point Transformer/P3-SAM）、逆向 CAD（ComplexGen/Point2CAD/CADParser）、CSG 推断（CSGNet/UCSG-Net/Shape2Prog/BSP-Net）。本质都是：encoder 压成 latent/特征 → head 把几何结构「读」出来。

### 4.5 分析即合成：用 Decoder 的 SDF 做微分几何（无需重训）

ShapeVAE decoder 输入 (z, x) 输出 SDF(x;z)。对其做微积分即可读几何：

| 想读的量 | 怎么从 SDF 算 |
|---|---|
| 表面 | 零等值面 {x ∣ SDF(x)=0} |
| 法向 | n = ∇ₓ SDF（归一化） |
| 平均/高斯曲率 | Hessian ∇²ₓ SDF 的特征值（主曲率 k₁,k₂） |
| 平面 | k₁ = k₂ = 0 |
| 圆柱面 | k₁ = 0，k₂ = 1/r |
| 球面 | k₁ = k₂ = 1/r |
| 马鞍面 | k₁ > 0，k₂ < 0 |
| 凹凸 | 法向朝向 + SDF 内外符号约定 |
| 相对位置 | 直接在 SDF 场查空间关系 |

→ **分析即合成**：encode → latent → decode 出隐式 SDF → 微分几何/MC/RANSAC 读几何。**无需重新训练**，是验证「latent 懂不懂几何」最快的实验。

### 4.6 Probing 实验配方

1. 拿预训练 encoder（ShapeVAE，或 ShapeNet 自监督的 PointNet/PointTransformer）。
2. 程序化生成带精确几何标签的数据（零人工标注）：立方体、不同深度方槽（开口/封闭）、半球、圆柱凸台、球、圆环；自动生成标签（平面/曲面、类型、半径、部件归属、是否封闭、OBB 尺寸、面相对位姿）。
3. 冻结 encoder，只训线性分类器/MLP，预测「平面还是曲面？」「开口还是封闭？」「OBB 长宽高？」「两面是否相邻？」
4. 看准确率：平面 vs 曲面通常 >90%（latent 线性可读曲率/平面性）；尺寸回归若归一化过则误差大（丢弃绝对尺度）；封闭性若数据全水密则全预测「封闭」（不表示开口）。
5. 再解冻 encoder 端到端微调 + 分割头/关系头 → 完整几何解析模型。

意义：高 probing 精度 = 属性在 latent 里且线性可分；低精度 = 被丢掉或非线性纠缠（需微调或换结构化 latent）。

### 4.7 三个必须清醒的现实坑

- **归一化吃掉绝对大小**：工件 50 mm 还是 500 mm，latent 可能不知道 → 训练时不归一化，或额外保留 scale 参数。
- **训练数据决定它认不认开口**：水密数据训练 → 「5 面开口盒子」喂进去 decoder 很可能自作主张补上第 6 面 → 开口理解需训练数据显式含开口样本并监督。
- **真实扫描有噪声/缺失/密度不均（sim-to-real gap）**：最稳落地是 **Hybrid**——DL 负责感知（分割、找部件、建对应），传统几何负责测量（RANSAC、OBB、检测开口、量公差）。

### 4.8 代表工作一览

| 方向 | 代表方法 |
|---|---|
| 形状 latent / 插值 | DeepSDF、FoldingNet、AtlasNet、ShapeVAE（Hunyuan3D） |
| latent 编辑 / 流匹配 | Hunyuan3D-DiT、流匹配 ODE |
| 部件分割（语义） | PointNet++、DGCNN、Point Transformer、PartNet、COSEG、P3-SAM、PartField |
| 基元 / 几何解析 | SPFN、HPNet、ParseNet |
| 逆向 CAD / B-rep | ComplexGen、Point2CAD、CADParser |
| CSG / 程序推断 | CSGNet、UCSG-Net、BSP-Net、Shape2Prog |
| 表示探测 | Linear probing / latent PCA / latent dissection |

## 第五章　核心结论与工程落地建议

### 5.1 核心结论

1. **拓扑层面**：5 面开口盒子与开口半球完全同胚（都是圆盘 disk：亏格 0、单边界环、χ=1），可弯曲拉伸互转，都不是「洞（handle）」。
2. **但「一样」仅限曲面拓扑**：加上凹凸方向（凹腔 vs 凸台）、CAD 语义（减材 vs 增材）、几何基元（5 平面 vs 1 球面）后完全不同——分割与拟合算法看到的正是这些差异。
3. **同胚只保证「存在」**，算法负责构造「好看」的路径；不需对应的两条路是 SDF 场插值与 latent 插值，需对应的传统路是网格参数化 + ARAP；路径不唯一。
4. **latent 插值最性感处**：把「每次重建对应」这个最脆最贵的步骤，一次性摊销成「训练一个 encoder」。
5. **平滑归功于 KL + 连续解码器**；流匹配的价值是给了「沿概率密度走、不掉出流形」的更聪明路径；代价是中间态只保证统计自然（适合设计/动画），不保证工程特征。
6. **latent token 确实把点云空间结构压成连续可插值的几何流形坐标**；做几何理解完全可行，且几何标签可程序化自动生成，比语义部件理解更干净更便宜。
7. **latent 不会主动「说人话」**，必须接 readout head（探针/分割头/关系头）或用 decoder 解码成 SDF 后做微分几何 + 传统拟合；单个全局 latent 不显式编码部件实例与相对关系，要这个必须引入 slot/part token 或走 CSG/B-rep 解析。

### 5.2 工程落地建议

- **最快验证几何理解**：SDF 插值 + Marching Cubes（Open3D/PyMCubes/scikit-image）看盒腔↔碗中间态；或 2D VAE（MNIST/CelebA）先建立 latent 连续流形直觉。
- **验证 latent 里有什么**：linear probing（冻结 encoder + 线性头），分别在「平面 vs 曲面」「开口 vs 封闭」「尺寸回归」上测。
- **精确/工业件**：libigl（ARAP、harmonic parametrization、LSCM）或 PyTorch3D，先做对应（functional maps/landmark）再 ARAP。
- **拓扑要变**：别用网格，直接用隐式/level set。
- **最实用的工业落地**：Hybrid——DL 分割 + 传统几何精修。把传统算法功底与新的 latent 表示结合，比端到端硬啃可靠得多。

## 第六章　从 Latent 几何理解到工业逆向 CAD 闭环

> 第四章结论「Hybrid」的完整展开。学术名：Iterative Primitive Fitting（迭代基元拟合）/ Hierarchical Decomposition（层次分解）/ fit-and-refine loop。

### 6.1 总体架构

输入工业零件点云 → 预处理（去离群、法向一致、体素下采样）→ **DL 多头输出逐点分割 mask 与基元类型推荐** → 对每片拟合基元并算残差 → 残差过大则回退重分片/换类型/重新预处理 → 过分割合并 → 检测正则关系并全局约束优化 → 为基元加边界、双向调整得到有界拓扑面 → 面面求交裁剪出有界边 → 顶点 → 边界环 → 欧拉公式验证 → 输出解析 CAD 模型（基元参数 + 布尔组合）。

**关键观念纠正**：一旦基元类型与参数确定，它就是解析表达（平面 n·x+d=0，圆柱轴+半径+中心），**不再需要点云**。点云只是拟合参数的观测；最终交付是解析基元的布尔组合——这才是相对 mesh/点云的核心优势：**无限精度、可编辑、可制造**。

### 6.2 第一枢纽：残差判据（点到基元距离）

| 基元 | 距离度量 |
|---|---|
| 平面 | \|n·p + d\| |
| 圆柱 | \|dist(p, 轴) − r\| |
| 球 | \|‖p−c‖ − r\| |

对整片算 RMS 或最大距离，与阈值比较：小则接受，大则回退。**真实扫描不能简单取 RMS**（噪声与飞点会把 RMS 拉爆，好基元被误判）→ 用鲁棒核（Huber/Tukey）或看分位数（如 95% 点距离）。

### 6.3 残差诊断：三种失败原因必须分开

| 失败原因 | 残差表现 | 正确对策 |
|---|---|---|
| 真的是多个基元（跨平面+柱面） | 残差集中在区域一侧 | 分片后重新拟合（DL 重分片） |
| 基元类型选错（自由曲面当平面） | 残差均匀分布、带系统曲率 | 换类型（自由曲面/NURBS/隐式兜底），分片无效 |
| 点云本身有问题（噪声/缺失/离群） | 残差零星分布、伴飞点 | 回退预处理（去噪/补全/鲁棒核），分片无效 |

盲目分片会把一个自由曲面切成一堆小平面（碎片），故必须先诊断再处置。

### 6.4 停止准则：MDL 防止过分割

**过分割是这套方案最主要的失败模式**。标准做法 MDL（Minimum Description Length）：

> MDL = L(residual) + L(model)

残差编码长度代表拟合精度，模型编码长度代表基元数量带来的复杂度。**只有当新增一个基元带来的「残差下降」大于「增加一个模型的代价」时才继续分片**。这是 Efficient RANSAC 一类经典方法的标准做法；对工业件尤其重要（CAD 零件是「少量、规则、带约束」的基元）。

### 6.5 合并与全局正则优化

- **合并（自底向上）**：迭代分片必然产生碎片（大平面被切成同法向两三片、圆柱被切成同轴两截）。合并准则：**同类型 + 参数接近（平面看夹角与距离差，圆柱看轴夹角/半径差/共线）+ 点云上空间邻接**；合并后重新拟合。
- **全局正则优化（GlobFit 思路）**：独立拟合是贪心的，丢失 CAD 最重要的**正则关系**（对面平行、相邻面垂直、孔阵列共轴等半径、特征对称、凸台与基体同心）。先独立拟合得初值 → 检测两两基元的平行/垂直/共轴/等半径/对称 → 作为硬/软约束做全局最小二乘，同时调整所有基元参数。**利用的是设计意图——「平行就是平行」，而非「接近平行」。**

### 6.6 从无限基元到有界拓扑面：边界的双向调整

| | 无限基元（拟合结果） | 有界拓扑面（目标） |
|---|---|---|
| 数学形式 | 方程（解析、无限） | 方程 + 边界环（loop） |
| 空间范围 | 无限延伸 | 被边界框定的有限 patch |
| 来源 | RANSAC/最小二乘 | 点云覆盖范围 + 面面求交裁剪 |
| 能否求交 | 能，但交线无限 | 能，交线被裁剪成有界线段 |

**边界两个来源**：
1. **点云投影的初始边界**：投到参数域（平面→2D、圆柱→θ-z 展开矩形、球→θ-φ），求包络（凸包/alpha shape/凹包）得锯齿但忠实的初始 loop。
2. **面面解析求交的理论边界**：平面∩平面=直线，平面∩圆柱=圆/椭圆/直线，平面∩球=圆——数学精确，**远精确于点云边界**。

**双向调整（方向不可混淆）**：
- **方向 A（点云 → 约束理论边界，定「取哪一段」）**：无限直线哪一段真实存在，由两面点云范围共同裁剪决定。点云在此作用是「存在性判定」。
- **方向 B（理论边界 → 修正点云边界，定「精确形状」）**：用解析交线（直线/圆弧）替换锯齿边界，把锯齿拉直。

→ A 定范围，B 定形状，合起来才是完整的有界 edge。本质是**从「测量值」跃迁到「设计值」**——最终边界是解析直线/圆弧，这正是 CAD 区别于 mesh/点云的本质：**边界解析、可无限细分、可精确求交、可制造**。

### 6.7 面-边-点拓扑的构建与验证

有界 face 两两求交并被边界裁剪 → 有界 edge → 交线交汇处得 vertex → edge 首尾相连成 loop → loop 界定 face → 完整 B-rep。

**凹凸判断在此直接派上用场**：法向朝内且负曲率 → 减材特征（孔/槽）；法向朝外且正曲率 → 增材特征（凸台）。这是判断布尔运算方向（加/减）的依据，是从基元走向 CSG 布尔树的关键。

**拓扑验证（欧拉公式，工业 CAD 硬标准）**：**V − E + F − L = 2(S − G)**（V 顶点、E 边、F 面、L 环、S 壳、G 亏格）。算不对说明拓扑有洞或存在碎面，拼装一定有问题。

### 6.8 两个必须注意的边界陷阱

1. **自由边（悬空边）没有理论交线可依赖**：薄壁边缘、未扫到区域、本就是开口处，无相邻面 → 求不出解析交线，只能靠点云边界 + 直线/圆弧拟合。「理论边界修正」**只对非自由边成立**。
2. **不要把自由曲线边界硬拉直**：若真实边界本就是自由曲线（两自由曲面相交、圆角过渡），硬用直线/圆弧修正会**过度修正**。修正前须按基元类型判断边类型：平面∩平面→直线可拉直；平面∩圆柱→圆可拟合；圆柱∩圆柱→空间解析曲线；涉及自由曲面→样条/隐式兜底。**基元类型 head 的推荐结果直接决定这条边该用什么曲线修正。**

### 6.9 代表工作一览

| 环节 | 代表方法 |
|---|---|
| DL 端到端基元拟合 | SPFN、HPNet、ParseNet |
| 传统经典基元检测 | Efficient RANSAC（RANSAC + MDL 停止准则） |
| 全局正则优化 | GlobFit |
| B-rep 逆向 | ComplexGen、Point2CAD、CADParser |
| CSG 推断 | CSGNet、UCSG-Net、BSP-Net |

→ 本章架构实际是把 **SPFN（DL 感知）+ Efficient RANSAC（传统拟合）+ GlobFit（全局正则）+ ComplexGen（B-rep 关系）** 串成一个闭环——当前工业逆向 CAD 的前沿思路。

### 6.10 落地建议与遗留深水区

**建议**：
- **不要一上来就全自动**：先用 V1 三级样本（S1 长方体 / **S2 带孔板+螺钉（核心）** / S3 倒角圆角相切）手工验证每环的残差阈值与 MDL 权重（对工业件极敏感，与传感器噪声强相关）。
- **发挥传统功底**：DL 只管「哪块是啥、大概多大」，精度全在 RANSAC、裁剪与曲线修正手里。

**遗留深水区**：
1. **尺度问题**：全局优化的「等半径/对称」约束是尺度无关的，但公差判定（残差阈值 ε 取多少合格）是**尺度相关**的；尺度问题理清之前阈无法定死。
2. **MDL 停止准则与 GlobFit 全局优化**：从「能跑通」到「精度够用」的分水岭，最值得深入啃的数学部分。

## 本卷要点速记

1. 5 面开口盒子 = 开口半球 = 圆盘 D²（χ=1、b=1、g=0）；开口凹槽不是 handle；凹凸是几何/嵌入性质而非拓扑性质。
2. 拓扑等价 ≠ 分割/基元等价：盒腔是多平面棱柱腔，碗是单张球面，算法路径完全不同。
3. 同胚变形三路线：SDF 插值（零对应、拓扑可自变）、Latent 插值（零对应、摊销对应成本）、网格 ARAP（需对应、最可控保特征）。
4. 插值发生在 **ShapeVAE 的 latent token** 空间；**KL + 连续解码器**是根本原因，流匹配提供「更聪明的路径」。
5. 三个前提：encoder 的 OOD 风险、直线走法会掉出流形（slerp / ODE 更好）、中间态只统计合理不工程合理。
6. latent 编码几何但分布式不解耦；几何基元理解可行性远高于语义部件理解（标签可自动生成）。
7. **分析即合成**：decoder 的 SDF 做微分几何即可读法向/曲率/基元类型，无需重训。
8. **Probing 配方**：冻结 encoder + 线性头测「平面vs曲面 / 开口vs封闭 / 尺寸回归」。
9. 三坑：归一化吃掉大小、水密数据不认开口、sim-to-real gap → 落地用 **Hybrid**。
10. 工业逆向闭环：DL 分片推荐 → 残差诊断（三种失败分开）→ **MDL 停止准则** → 合并 → **GlobFit 全局正则** → 边界**双向调整**（点云定范围、理论定形状）→ 面-边-点拓扑 → 欧拉公式 V−E+F−L=2(S−G) 验证。
11. 边界两陷阱：自由边无交线（只靠点云拟合）；不要硬拉直自由曲线边界。
12. 深水区：**尺度相关阈值**、**MDL 与 GlobFit**。
