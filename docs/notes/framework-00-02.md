## 第 0 章　立项依据：行业现状与定位

### 0.1 点云 → 三角网格：已成熟，但不是终点

- 代表方法：Screened Poisson（SPSR）、NKSR（NVIDIA, CVPR 2023）、POCO、ConvONet。NKSR 类可单模型处理百万级点、数秒完成、跨数据集泛化。
- **本框架把该环节当现成前端直接用，不作为研究内容**。
- 两个必须记录的局限（均直接相关）：
  1. **锐边普遍保不住**。评估中「水密」一列几乎全 Yes，「锐特征」一列几乎全 Moderate/Low（SPSR Moderate、OccNet Low、DeepSDF Low；仅 ConvONet/POCO/NKSR 达 High）。即：能闭合成壳，但**棱是圆的**。
  2. **反直觉：网格越精细，后续分割反而越难**。Analysis Situs 记录「对极高精度网格的分割可能产生 zig-zag 图案……网格单元越小，越难判断一个单元属于平面还是圆柱」（自述为观察推测，未严格证明）。推论：高分辨率相机的高质量网格，对下一步基元分割不一定是好事。

### 0.2 网格/点云 → B-rep：远未解决

数据均在**理想条件**下取得（点云直接由精确 CAD 几何采样，无噪声、无遮挡、无配准误差），ABC 数据集 GT：19.2 面 / 48 边 / 31.5 顶点。

| 方法 | 面数（预测/GT） | 边数 | 顶点数 |
|---|---|---|---|
| SEDNet + Point2CAD | 7.9 / 19.2（41%） | 18.2 / 48 | 12.7 / 31.5 |
| NVDNet | 22.8 / 19.2（119%） | 67.7 / 48 | 53.2 / 31.5 |
| HoLa-BRep | 16.0 / 19.2（83%） | 44.5 / 48 | 29.7 / 31.5 |
| DualBrep | 19.3 / 19.2（100%） | 55.8 / 48 | 40.2 / 31.5 |

- 即便最好方法能猜对面数，**边与顶点仍分别多估约 16% 与 28%**；Point2CAD 一类直接**漏掉近六成面**。
- **有效性（validity rate）**——输出能否成为合法实体：AutoBrep（Autodesk, SIGGRAPH Asia 2025）**70.8%**；HoLa-BRep（SIGGRAPH 2025）**82%**。即最干净条件下仍有 **18%–30% 结果不是合法实体**。
- ParaCAD（GPT 自回归，58.3 万实例）声称生成水密 B-rep，但审稿意见指出「水密 B-rep 核心主张被自身表 4 大幅削弱」「二值规划并不强制闭合的 2-manifold，与『确保拓扑有效性』不符」→ 最新 SOTA 的水密声明尚被判定名不副实。
- **商业侧同样是交互式而非全自动**：
  - 主流工具：Geomagic Design X、PolyWorks|Modeler、SOLIDWORKS ScanTo3D、NX Convergent Modeling、Rhino + Mesh2Surface、FreeCAD（均可导 STEP）；
  - 但均非全自动，业界共识：「全自动的设计意图恢复仍难以实现……由人类工程判断决定这个零件应当是什么」；
  - Autodesk 自述：mesh → solid「是整个流程中最困难的，通常需要人类技能与干预」；
  - Fusion 360 的 Convert Mesh 明确定位于「块状机械形状」（平面+柱面特征），自由曲面件几乎无从下手；
  - 邻近领域佐证：Scan-to-BIM 自动化率干净室内 70–85%、杂乱现场 55–70%，4–12h 计算后仍需 2–6h 人工复核。

### 0.3 定位：我们做的事没有被解决，也没有被替代

「网格已成熟」≠「不必做」，理由三条：

1. **网格缺失的不是精度，是本体**。网格=近似/依赖分辨率/不可编辑/无特征树/制造业常拒收；B-rep=精确/可编辑/水密/工业标准。最直接对照：把一个孔移动 5 mm，CAD 里改一个草图尺寸；网格上那个孔根本不是特征，只是「恰好没有三角形的一块区域」。
2. **下游不收网格**。CAM/CNC、CAE 有限元、装配验证、干涉检查均要求实体。
3. **目标不是「更准的表面」，而是「能进物理引擎的结构」**：厚度、质量、接触面、运动副、装配约束——这些是语义，不是几何精度。

正面依据：Analysis Situs 把本框架所走路线命名为 **Find surface – extend – trim**，开宗明义「该方法遵循 B-rep 的构造原理：边与顶点由高层拓扑实体的相交得到」（即本文 5.3 节路线）。既有路线的死结与本路线应对：

| 其他路线的死结 | 本路线应对 |
|---|---|
| 「区域之间真实边界的重建似乎不可能」 | 边由解析面求交得到，不从网格提取 |
| 「平面—圆柱平滑连接处有不可避免的 zig-zag」 | 同上，不依赖分割边界 |
| 「无原始 B-rep 时，参数无法自动确定」 | 阈值由采样密度与拟合残差算出，不由经验定 |
| Quad-based：「拓扑不尊重几何」、拓扑实体数量爆炸 | 拓扑由解析面交决定，天然尊重几何 |

结论：该路线并非凭空构造，领域内已被识别为正确方向，但过去二十年缺三个条件——**大规模 CAD 数据、可用开源几何内核、能提候选的神经模型**（现均已齐备，见第八章）。

## 第 1 章　场景对象与重建目标

### 1.1 场景对象：人类制造物（按**可分解性**划分，不按物体类别）

理由：同一室内场景里桌子走硬路线、盆栽走软路线，按场景划分必然自相矛盾，按可分解性划分则自洽。

人造物的三条可判定判据（已确立，对应 piecewise smooth 假设）：

| 判据 | 含义 | 数学形式 |
|---|---|---|
| 部件级可分离 | 可切成有限个部件，边界明确 | 存在分割，部件间交集落在其边界上 |
| 表面分片光滑 | 每个部件表面由有限个光滑曲面片构成 | 片内 C¹/C²，片间沿 crease 相接 |
| 曲面类型低熵 | 曲面片类型集中在少数解析族 | 平面/柱/锥/球/环/拉伸/旋转 |

- 三条同时成立即落在 **CAD 表达域**内。
- 同一物体内部可混合处理（茶杯：杯身旋转面、把手自由曲面、釉面纹理层）。
- **失效检测几乎免费**：基元拟合残差本身就是异常分数；残差超阈值即自动降级为自由曲面分支，无需额外训练判别器（合理推论）。

### 1.2 重建目标

| 层面 | 目标 | 说明 |
|---|---|---|
| 表示 | **装配体**，而非布尔并集 | 保留部件身份、位姿、配合约束、运动副 |
| 格式 | B-rep / STEP AP242 | 原生支持装配：occurrence 带 placement transform；AP242 Ed.2 含 Mating Domain；区分 As-Designed / As-Built |
| 质量 | 水密 + 可判定性标注 | 水密是必要而非充分；须同时输出置信度与开放边界 |

- **水密是低门槛**：一个「肿瘤块」本身就是完全合法的水密实体。真正判据不是「能不能闭合」，而是**闭合方式是否唯一地被证据与约束确定**。
- 多保真度输出（合理推论）：LOD0 理想化 B-rep（可进 CAD/CAE）→ LOD1 + 变形场（可进物理仿真）→ LOD2 + 细节层（可渲染）。三层共享同一套拓扑与参数化，细节挂载量不同。

### 1.3 进一步收窄：工业对象（机械零件/钣金/结构件/装配体/工装夹具/标准件），排除艺术造型、雕塑、自由形态外观件

核心判断：工业对象在满足功能要求的前提下，**几何与拓扑必然简洁**——由制造可行性、材料成本、设计难度、加工难度共同决定，四者方向一致、相互强化。

| 层面 | 机制 | 导致的几何特征 |
|---|---|---|
| 功能 | 形状服务功能，冗余几何只增成本与失效点 | 形状与功能强对应，无装饰性几何 |
| 材料成本 | 材料用量直接决定成本，复杂形状废料率高 | 壁厚趋于均匀、去除多余体积 |
| 设计难度 | 几何越复杂，参数化建模/约束求解/公差标注越难 | 优先可参数化的规整形式 |
| 加工难度 | 刀具可达性、拔模斜度、装夹次数、最小圆角半径、标准刀具尺寸 | 平面/柱面/回转体/等壁厚/标准孔径占主导 |

→ 推论：**工业对象曲面类型分布是低熵的**，高度集中于少数解析族（平面、圆柱、圆锥、球、环、拉伸体、回转体 + 有限 NURBS 过渡面）。

| 维度 | 工业对象 | 自然/艺术对象 |
|---|---|---|
| 曲面类型 | 低熵，集中少数解析族 | 高熵，自由曲面为主 |
| 表面 | 分片光滑，片内平整 | 处处变化，局部高频起伏 |
| 部件边界 | 明确、可分离 | 渐变过渡，无明确分界 |
| 重复性 | 标准件/阵列/对称普遍 | 无重复，个体各异 |
| 先验可用性 | 强（标准件库、工艺约束、设计规范） | 弱 |

→ 数据策略：**以工业模型库为主**训练与开发。收益一：先验强且可枚举；收益二：类型识别门槛下降；收益三：「面集完整性」真难点（5.8）搜索空间大幅收缩。代价：艺术造型/自由形态件不在覆盖范围（主动接受的限制）。

## 第 2 章　整体算法框架（核心章）

### 2.1 三层表示（对象侧）

| 层 | 内容 | 性质 | 先验/正则 | 级别 |
|---|---|---|---|---|
| L0 规范基形 | 部件 + 解析/光滑曲面片 + 装配关系 | 低维、离散、良态 | CAD 先验、标准件库、工程约束 | 假设 |
| L1 变形场 | 规范形 → 实际观测姿态的映射 | 连续、欠定 | ARAP、体积保持、循环一致性 | 假设 |
| L2 表面细节 | displacement / 法线 / BRDF | 高频、近乎确定性拟合 | 纹理与材质先验 | 已确立 |

关键收益：**每层先验/正则/监督信号/不确定性来源完全不同，本就不该塞进同一个网络**。L1 的存在使软体、织物、下陷海绵被纳入框架而不当例外：变形场承担「不规则」，基形承担「规则」，CAD 先验只作用于基形。

### 2.2 主流程：证据优先的约束传播（「点云 → 面 → 实体 → 装配」）

| 序 | 阶段 | 要点 |
|---|---|---|
| 1 | 点云 → 面 | 可经三角网格中间态；**基元只用远离边缘的内部点拟合** |
| 2 | 面处理 | 补孔洞；剔除面上附着物团块并补面；面片可信度分级 |
| 3 | 选取可构成实体的面组 | 按证据充分度（observed 占比）排序 |
| 4 | 构建实体 | 缺失面依邻接/装配/物理关系补全 |
| 5 | 已建实体反作用于剩余面 | 作为新约束源，界定/修正/补全剩余面 |
| 6 | 迭代 3—5 | 直至无法继续 |
| 7 | 剩余面保持不动 | 标注为开放边界 |
| 8 | 装配固化 | 确定部件间配合类型与位姿 |

- 内核：**「最可信优先」的贪心 + 约束传播**——先做证据最充分的实体，该实体随即成为新约束源，使后续每步不确定性单调下降。明显优于「所有部件并行独立求解」。
- 三项必须补足的机制（合理推论）：① **可回退的假设栈**（每个实体记录依赖假设，冲突时按 provenance 回退）；② **可判定的终止条件**（自由度记账，约束数 < 未知量数即判欠定，停止并标注）；③ **装配全程参与**（装配关系作为软约束贯穿 1—7，而非仅在最后固化）。

### 2.3 模块结构：神经符号循环（「提议 + 验证」范式）

| 模块 | 类型 | 职责 | 级别 |
|---|---|---|---|
| 几何编码器 | 神经 | 点云/网格 → 面片级特征（类型、参数、置信度） | 已确立 |
| 部件关系图 | 神经（GNN/Transformer） | 面—面、部件—部件关系与配合类型推理 | 合理推论 |
| 程序/假设解码器 | 大模型（LLM） | 输出候选：CAD 程序骨架、标准件候选、约束假设 | 合理推论 |
| 符号验证器 | 传统（几何内核） | 执行、求交、检查水密性与约束一致性 | 已确立 |
| 渲染—比对 | 可微渲染 | 结果投回输入视角比对，残差驱动修正 | 合理推论 |

- **关键设计原则：神经部分永远不直接输出最终几何**，只输出「候选」与「权重」，最终几何由符号部分组装并验证。
- 三重收益：水密性由符号端构造性保证；大模型几何幻觉被验证器拦截；不确定部分自然落到「候选集 + 置信度」而非错误答案。
- **大模型不能直接做几何推理（已确立，有实测）**：SSI-Bench 最强闭源 33.6%、开源 22.2%，人类 91.6%；失败集中在 structural grounding 与 constraint-consistent 3D reasoning（含 occlusion reasoning）。TopoBench 诊断：瓶颈在**从空间表示中提取约束**，而非推理本身。
- 可借鉴范式：AlphaGeometry 式分工——**符号负责「对不对」，神经负责「下一步试什么」**。梯度无法穿过符号元素的难题，可用程序执行器的可微松弛（Shape2Prog / ProGRIP / Point2Cyl）训练期代理、推理期替换真实执行器。

### 2.4 范式选择的判据（不是「谁更先进」，而是「该环节典型失败模式是什么」）

| 典型失败模式 | 采用 | 理由 |
|---|---|---|
| 精度不足/噪声被放大 | 传统解析方法 | 解析拟合不放大噪声，精度优于单点测量（面由大量点拟合，噪声被 √N 平均） |
| 需要阈值/参数、无法自动确定 | 深度学习 | 学术死结「无原始 B-rep 时参数无法自动确定」；学习式对噪声鲁棒，可避开手工阈值 |
| 欠定、需要外部知识 | 大模型提候选 + 符号验证 | 大模型提供可能性，符号端判定对错 |

**核心原则：深度学习/大模型输出「决策」（分类、分割、候选）；几何一律由解析方法算出**。最常见错误是让网络直接输出几何坐标——会同时丢掉解析精度与可验证性。

### 2.5 分阶段流程（P0—P8）

| # | 阶段 | 范式 | 选择依据 |
|---|---|---|---|
| P0 | 预处理：多视角融合、离群剔除、边缘点标记、法向定向、局部密度图 | 传统 | 确定性计算；法向因相机位姿已知而免费获得（5.5） |
| P1 | 面片感知：逐点预测基元类型/参数/置信度，区域生长 | 深度学习为主 | 对噪声鲁棒，避开手工阈值 |
| P2 | 区域拟合 + 类型判定：大区域优先，残差驱动细分 | 传统解析 + 学习式类型先验 | 拟合要精度，判定要鲁棒 |
| P3 | 边界性质判定：锐边/倒角/圆角/相切 | 传统统计 + 学习式分类器 | 见 5.4.2 |
| P4 | 部件分割 + 骨架构造：面集推导、顶点/边/邻接、定向传播 | 符号（几何内核）为主 | 拓扑是离散组合对象，符号端天然保证水密 |
| P5 | 补全与假设生成：八级依据派生；欠定时生成候选 | **混合（三类范式交汇）** | 有据者走符号；欠定者由大模型提候选 |
| P6 | 装配求解：配合类型识别 + 位姿与面参数联合优化 | 学习式类型 + 传统优化 | 类型是分类，求解是优化 |
| P7 | 验证回检：水密性、L1—L4 检查、渲染—比对 | 符号 | 可判定，无需学习 |
| P8 | 输出与标注：LOD、provenance、候选集、主动消歧 | 符号 + 人机 | — |

**P5 是唯一三类范式真正交汇的阶段，也是大模型主入口**；其余阶段要么不需外部知识（P0/P4/P7/P8），要么仅需鲁棒的分类与拟合（P1/P2/P3/P6）。

### 2.6 大模型的四个入口（角色一致：均为「提议者」，输出必经符号验证）

| 入口 | 阶段 | 触发条件 | 大模型做什么 | 符号端做什么 |
|---|---|---|---|---|
| A 欠定候选 | P5 | 自由度记账判欠定 | 提议标准件规格、结构假设 | 验证是否与观测一致 |
| B 骨架提议 | P5 | 面集无法闭合 | 提议候选拓扑/CAD 程序 | 验证能否闭合成水密实体 |
| C 功能语义 | P7 | 部件分类完成后 | 提供「螺钉须穿过被连接件」类常识 | 检查与几何是否冲突（L4） |
| D 先验偏置 | P3/P6 | 分类歧义时 | 提示「更像焊缝还是倒角」 | 以拟合残差与约束一致性裁决 |

### 2.6.1 关键区分：空间推理不行，程序生成可行

| 能力 | 表现 | 原因 |
|---|---|---|
| VLM 空间推理（遮挡、心理旋转、力路径） | **差**，有硬数据支撑 | 瓶颈在从空间表示中提取约束 |
| LLM 程序生成（CadQuery/操作序列） | **相对可行** | 输出是符号，可执行、可验证 |

CAD-Recode 一类以小参数量模型输出 CadQuery 代码即取得远超纯几何方法的精度，原因正在于此：输出能被精确执行与检验，它无需自己「算对」，只需提对方向。

### 2.7 为什么多阶段多范式

- 学术少见的原因（均与「是否易发表」相关，与「是否正确」无关）：① 多阶段无单一创新点；② 难做漂亮端到端对比、credit 分配不清；③ 评测困难——Chamfer distance 衡量不了拓扑，而多阶段优势恰在拓扑。
- 工业界一直是多阶段：Geomagic Design X、PolyWorks|Modeler、NX Convergent Modeling 全为分阶段管线，只是构成为「传统方法+人」。真正差距在：过去二十年缺失的**可学习感知前端 + 能提候选的大模型**现已齐备。
- **复杂度是必要的，而非堆砌**：判断标准不是「能否合并」，而是**输出的数学性质是异质的，单一可微模型无法原生同时产生**。

| 输出成分 | 数学性质 | 可微？ |
|---|---|---|
| 几何参数（面方程） | 连续 | 可 |
| 拓扑（面—边—顶点图） | 离散、组合 | 不可 |
| 类型（平面/柱面/倒角） | 离散 | 不可 |
| 装配关系、功能语义 | 符号 | 不可 |

→ 纯可微网络输出拓扑必须把离散结构松弛为连续，松弛本身即引入虚假解——**这正是当前最好的 B-rep 生成方法水密性仅 70%–82% 的根源**。本框架把每类输出交给数学性质匹配的范式：连续→拟合，离散→分类，组合→符号内核，欠定→大模型提候选。

### 2.8 级联误差与四道防线

| 机制 | 作用 | 出处 |
|---|---|---|
| 逐阶段 provenance 标记 | 始终知道每个结论是实测、推断还是假设 | 3.2、5.9 |
| 符号端逐阶段验证 | 错误在产生处即被拦截，不向后传递 | P4、P7 |
| TMS 非单调回溯 | 后续发现矛盾时可回退至上游修正 | 6.4 |
| 残差回检 | 最终结果投回输入视角比对，作全局兜底 | 5.13 |

→ 具备四条，本框架不是「脆弱的级联」，而是**「带验证与回滚的级联」**——这是它与朴素 pipeline 的本质区别。

### 2.9 精简视图：四层 + 两个环

| 层 | 包含阶段 | 范式 | 职责 |
|---|---|---|---|
| 感知 | P0—P3 | 学习 + 统计 | 从点云得到面片的类型、参数与边界性质 |
| 构造 | P4、P6 | 符号 | 骨架、拓扑、装配求解 |
| 补全/提议 | P5 | 规则 + 大模型 | 派生未见面；欠定时生成候选 |
| 验证/输出 | P7、P8 | 符号 + 人 | 检查、标注、人机交接 |

两个环：**内环**（构造 ⇄ 验证）P4 → P7 → 回 P4 修正；**外环**（提议 → 构造）验证失败 → P5 提候选 → 回构造重算。
→ **复杂度集中在「感知 → 构造」这一接口**：它是四层中唯一跨范式接口（连续 → 离散），也是级联误差最易发生处，**该接口定义应作为实现的首要设计对象**。

### 2.10 反向考量：为何此前少见

既然合理却少见，须考虑「有人试过并失败了」。本文认为此前失败原因是具体且**已消失**的：① 感知前端太弱（DL 成熟前只能靠手工特征与阈值）；② 缺大规模 CAD 数据（ABC 2019 年发布，Fusion360 Gallery Assembly 更晚）；③ 缺能提候选的大模型；④ 几何内核昂贵（OpenCASCADE 成熟是近十年事）。四样条件同时到位即最近两年 →「少见」更可能是**时机刚至**而非方向有误（**此为假设**，须由最小闭环实验检验）。
