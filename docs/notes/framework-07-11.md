## 第 7 章　不确定性的处理与人类介入

### 7.1 三级策略

| 级 | 动作 | 说明 |
|---|---|---|
| 1 | **输出候选集** | 如 M8×20 / M8×25 + 各自置信度，不作单一断言 |
| 2 | **主动消歧** | 计算何种观测能区分候选 → **规划新视角 → 机器人补拍 → 重算** |
| 3 | **人类介入** | 仅当物理上确实不可观测（如盒子内部）时才提交给人 |

第 2 级是本硬件配置的**独特价值**：相机在机械臂上、位姿已知，**可以再拍一张**。且因候选集来自标准件库而**离散有限**，消歧观测可直接算出——只需一个能区分 M8×20 与 M8×25 的视角，而非笼统地「多拍几张」。

> 推论：**大部分「不可判定」其实是「当前采集方案不够好」，而非真的不可判定。** 把人类介入从第一道防线降为最后一道，自动化率将显著上升（合理推论）。

### 7.2 输出形态
- **候选集而非单一答案**：对不可判定项输出「A 或 B，无法区分」+ 置信度。
- **开放边界而非强行闭合**：欠定处保留开放边界并标注。
- **可判定性标注**：如「内部空腔不可判定，质量属性不可信」。
- **理想化可逆**：细节被重新安置到补充层而非删除，符合 STEP AP242 对 PMI 与补充几何的支持。

## 第 8 章　数据基础：可用资源与构造方式

> 数据曾被视为本方向的首要瓶颈。经检索确认：**工业模型库、学术数据集、合成扫描工具与评测口径均已具备，数据本身不再是第一位的障碍。**

### 8.1 工业模型库

| 来源 | 规模 | 格式与获取 | 特点 |
|---|---|---|---|
| TraceParts | 2,283 个厂商目录、约 **2.9 亿**可检索件号 | STEP 及 60+ 格式，注册免费 | 厂商认证；紧固件、密封件、液压气动覆盖最全 |
| GrabCAD | **700 万+** 模型 | STEP / SLDPRT / X_T / SAT 等，注册免费 | 社区上传，质量参差；含完整装配体与 BOM |
| McMaster-Carr | **70 万+** 零件带 CAD | STEP / SLDPRT / Parasolid，免费，**提供 API** | 自建模型、精度高；紧固件最全 |
| 3Dfindit（CADENAS） | 800+ 厂商目录 | 100+ 原生/中性格式 | 厂商认证数字孪生 |
| 3D ContentCentral | 数百万认证供应商零件 | 多种原生 CAD 格式 | Dassault 运营 |

> ⚠️ McMaster-Carr 提供的是 **simplified, non-threaded models**。对本框架**通常是有利的**——螺纹本就属 L2 细节层，不应进入 L0 基形。

### 8.2 学术数据集（关键在装配真值）

| 数据集 | 规模 | 提供的真值 |
|---|---|---|
| **Fusion360 Gallery Assembly** | **8,251 装配体 / 154,468 零件 / 32,148 joints** | JSON 含 joints、as_built_joints、contacts（接触面）、holes（孔类型/尺寸/方向/位置）、tree（层级）；.obj 以 `g face N` 把三角形映射回 B-rep 面——**逐面标签现成** |
| ABC | 100 万+ B-rep | 参数化曲面与曲线解析表示 |
| Better STEP | ABC + Fusion360 转制 CC0 授权 | HDF5 紧凑格式，**绕开每个计算节点都需 CAD 内核授权**的问题——大规模训练的硬需求 |
| HistCAD | 17 万可执行建模历史 | 草图几何 + 几何约束 + 特征操作 + STEP |
| MFCAD++ / DeepCAD | 59,655 / 178,238 | 加工特征标注 / CAD 操作序列 |

### 8.3 合成扫描
可选工具：**HELIOS++**（C++ 开源，支持光束发散、全波形、强度、逐点分类标签、随机误差建模）、BlenSor（Blender 插件）、最简的 Open3D 光线投射。
针对「理论可见性 ≠ 真实可采」：已有 2025 年工作——先用结构光仿真生成初版点云，再用 **3DSCP-Net**（在大量真实扫描上训练的覆盖率预测网络）判断「真实扫描时哪些区域其实采不到点」，复现边缘丢失、表面反射、互反射造成的真实缺失。**正对应本框架最关心的「哪些面真正可观测」。**

### 8.4 三个关键判断

**判断一：可见性真值可以免费算出。** 给定 CAD 模型与已知相机位姿，可精确判定每个 B-rep 面属于「完整观测 / 部分观测 / 完全未观测」。→ provenance 标签（observed / inferred-intra / inferred-inter / assumed）**可自动生成，无需人工标注**。它使「哪些面该被推断」这一核心判据成为**有监督的真值**，训练与评测均立得住。

**判断二：as-designed CAD 恰恰是正确的训练目标。** 本框架输出理想化的 L0 规范基形，而 as-designed CAD 本身就是理想化的，真实与理想的差异按设计应落入 L2 细节层。→ 用 as-designed 数据训练 L0 **不是妥协，而是对齐**。

**判断三（两个 gap，合理推论）：**
- as-designed 与 as-built 的差异：CAD 不含制造误差、装配缝隙、磨损 → domain gap。
- 可见性的 sim-to-real gap：纯光线投射是**理论可见性**，真实相机在边缘、反光、暗表面会丢点 → 需覆盖率预测或真实扫描校正。

### 8.5 评测口径
前人已指出常用指标（如 Chamfer distance）**衡量不了拓扑与装配关系**。两套现成口径：
- **BIMNet**（Automation in Construction 2025，buildingSMART 最佳学生研究奖）：几何 + 拓扑双维度的 as-built 重建评测指标，专门针对 scan-to-BIM。
- **虚拟试装配（VTA）**口径：螺栓孔中心提取（RANSAC 圆/柱拟合）、法兰面拟合、as-built 与 as-designed 法向夹角偏差等**工程可解释指标**。

### 8.6 结论：数据不再是首要瓶颈
真需要自建的**仅有一项**——注入 as-built 变异（制造误差、装配缝隙、磨损），或直接用现有机器人扫描真实零件。

**缺口优先级重排：**
1. **拓扑骨架的搜索策略**（无现成方案，且为架构脊梁）
2. 几何内核选型与鲁棒性
3. 注入 as-built 变异
4. 评测协议定制
5. 标准件库
6. 功能语义来源（可增量补充，排最后）

## 第 9 章　适用边界与开放问题

### 9.1 边界（诚实声明）

| 项 | 说明 |
|---|---|
| 适用 | 工业场景人造物：部件可分离、表面分片光滑、曲面类型低熵、几何与拓扑简洁（1.3） |
| 不适用 | 艺术造型、雕塑、手作器物、自由形态外观件；城市、自然景观、有机物——无简洁性先验，须退回通用重建 |
| **过度规整化风险** | 先验过强会强行把磨损、锈蚀、变形「掰直」。此类错误**看起来非常可信**，比一眼可辨的伪影更具欺骗性 |
| 相切过渡退化 | 无真实棱边时 SSI 退化，须改用约束拟合；此类区域本质 ill-defined，应留到最后处理 |
| 数据缺口 | 公开 CAD 数据以机械零件为主；建筑钢构、钣金、焊接件、装配体的大规模公开数据集稀缺 |
| B-rep 水密率上限 | 即使在干净 CAD 数据上，当前最佳方法的自动水密率仍约**七成**——行业级难题，非本框架独有 |

### 9.2 三个开放问题
1. **功能语义的来源**：现成本体/知识库，还是依赖大模型输出常识？这决定语义层的实现方式与可靠性边界。
2. **面集完整性的自动判定**：骨架已可由解析面计算、定向已由观测确定（第五章），剩下的是——如何判定面集是否完整，尤其「漏掉倒角、两大面被当作直接相接」这类**能闭合、能水密、但结构错误**的情形。欧拉公式只能查面数，对此无能为力，须依赖残差回检与功能语义。**这是当前唯一的结构性难点。**
3. **联合求解的收敛性**：建议折中为「先独立求解作初值，再联合精修」，需在部件数量较多时验证收敛性。

### 9.3 建议的验证次序
1. **先验证 L0 表示本身**——L1（变形场）与 L2（细节层）均有成熟现成方案可借用；真正决定成败的是「规范基形该如何表示」。
2. **再打通主流程**——以证据优先的约束传播为主线，用标准件密集的场景（机械装配体）验证闭环。
3. **最后补语义层**——待功能语义来源确定后接入 L4 检查与非单调回溯。

## 第 10 章　工程实现估算

> 本章整体标注为**假设**（按 0.4 约定）。所有数字均为量级推算，依据可比规模工作的公开配置，**仅可用于预算，不可用于排期**。

### 10.1 核心结论：主干很轻
P0—P8 中需训练的只有 **4 个阶段（P1、P2、P3、P6）**；其余 4 个（P0、P4、P7、P8）为纯符号方法，不需训练。需训练的 4 个中**只有 P1 是重的**。
→ 粗估：**不含大模型，全部可训练参数在 100M 以内**——小于一个 ResNet-152。
→ 部署意义：相机搭载于机械臂，推理成本须计入；数十 M 级模型在单卡上处理数万点为**毫秒至百毫秒量级**，对第 7 章的主动消歧闭环（规划 → 补拍 → 重算）友好。

### 10.2 分阶段模型规模

| 阶段 | 实现方式 | 参数量 | 是否必需 |
|---|---|---|---|
| P0 预处理 | 无（几何计算；HELIOS++ / Open3D） | 0 | 必需 |
| **P1 面片感知** | 稀疏卷积 / Point Transformer（PTv3 一类） | **30–60M** | 必需（**最重**） |
| P2 类型判定 | 轻量 MLP / 小 Transformer，或复用 P1 | 5–20M | 可与 P1 合并 |
| P3 边界性质判定 | 法向直方图 + 小分类器 | <10M | 必需（很轻） |
| P4 骨架构造 | 无（几何内核 **OCCT**） | 0 | 必需 |
| P5 补全/提议 | 规则 + 标准件库（第一版）；LLM 1.5B–7B（后续） | 0 / 1.5–7B | 第一版可不用大模型 |
| P6 配合类型识别 | 部件图上的 GNN / 小 Transformer | 10–30M | 装配场景必需 |
| P7 验证回检 | 无（符号检查 + 可微渲染） | 0 | 必需 |
| P8 输出标注 | 无 | 0 | 必需 |

参考锚点：ParaCAD（GPT 自回归，15 层 Transformer、768 维）在 **58.3 万**实例上训练，公开配置 5 天 / 16 张 A800；面片分割一类（PTv3 骨干）在**数百万**模型上训练。→ 本框架主干规模**显著小于**这两者。

### 10.3 训练数据

| 项 | 数量/方式 | 说明 |
|---|---|---|
| CAD 源模型 | **1–10 万装配体** | 以 Fusion360 Gallery Assembly + ABC 子集起步 |
| 每零件采样 | 4,096–10,240 点 | 参照 ParaCAD：先在面参数域内按固定点数采样，再 FPS 至均匀点集 |
| 视角数 | 每装配体 5–20 个 | **采用机器人实际采集轨迹更佳** |
| 合成扫描 | 必需 | HELIOS++ 或 Open3D 光线投射；**必须叠加真实缺失**（边缘丢失、反光空洞） |
| 自动标注 | 免费 | 可见性标签、逐面类型、邻接关系、provenance 全部可自动生成（8.4） |

> 起步量级：**1 万装配体 × 10 视角 = 10 万帧**，足以支撑 P1 训练。

### 10.4 训练时间

| 项 | 配置 | 时间 |
|---|---|---|
| **数据生成** | CPU 密集，32–64 核并行 | **3–10 天（最易被低估）** |
| P1 面片感知 | 8 × A100 | 2–5 天 |
| P2 / P3 | 单卡 | <1 天 |
| P6 配合识别 | 单卡 | 1–2 天 |
| P5（若微调 LLM） | 8 × A100 + LoRA | 2–7 天 |

> ⚠️ **数据生成可能比模型训练更慢。** 合成扫描与可见性标注属 CPU/IO 密集型，而预算时往往只计 GPU 时间。

### 10.5 硬件配置建议

| 用途 | 配置 |
|---|---|
| 开发/第一版 | 单卡 A100 80G（或 4090 24G）+ 32 核 CPU / 128G 内存 / 2TB NVMe |
| 正式训练 | 8 × A100（可租用） |
| 部署推理 | 单卡即可；视需要可考虑边缘部署 |

### 10.6 分三版投入

| 版本 | 内容 | 需要训练 | 投入估算 |
|---|---|---|---|
| **V1 验证路线** | 手工/半自动实现 P0—P8（Open3D RANSAC 拟合 + 手工规则 + OCCT） | 完全不需要 | **1–2 人月** |
| V2 学习式感知 | 以学习模型替换 P1 / P3 中的手工规则 | 需要 | 数据 1–2 月 + 训练 1 周 |
| V3 语义与提议 | 增加 P6 配合识别、P5 大模型候选 | 需要 | 后续 |

**V1 的价值不在于「能用」，而在于三点：**
1. **暴露全部接口问题**——复杂度集中在「感知 → 构造」这一跨范式接口（2.9）。
2. **检验几何内核鲁棒性**——本文判断最先崩在 OCCT 的退化情形上（0.2、9.1）。
3. **产生真实失败案例**——以此决定 V2 究竟该学什么。

此外，V1 跑通后才具备定义「哪些错误可接受」的真值基础（5.9），而该定义**直接决定 V2 的训练目标**。

### 10.7 三点提醒
1. 上述数字均为**量级推算**，非本项目实测。仅用于预算，不用于排期。
2. **P5 的大模型在第一版可以完全不用。** 3.2 的八级派生依据中前 7 条全为符号规则，仅第 8 条需大模型提候选；简单工业件上走到第 8 条的比例可能很低。先做规则 + 标准件库，大模型留至 V3。
3. **最大的不确定性不在训练，而在数据生成的真实性。** 若合成扫描过于「干净」，V2 训得的模型在真实点云上会显著退化。8.4 的「叠加真实缺失」**不是可选项**，它决定 V2 能否可用。

## 第 11 章　三阶段实践路线

> 核心原则：**每版都必须产出可用于决定「下一版该做什么」的信息**，而不只是产出一个更好的模型。

### 11.1 V1：验证路线（不训练）

**11.1.1 目标**：用最小代价证明 P0—P8 链路能走通，并定位它到底在哪里崩。V1 不追求可用，也不追求精度；它追求的是**暴露问题**。

V1 的三项产出：① **接口规格**（P2 → P4 到底传什么）；② **失败案例集**（哪些情形会崩、崩在哪）；③ **「哪些错误可接受」的真值基础**（决定 V2 训练目标）。第三项尤为关键——没有它，V2 就不知道该学什么。

**11.1.2 样本设计（三级递进，均由易到难、每级可手工核验）**

| 级别 | 样本 | 覆盖的环节 | 为什么这样设计 |
|---|---|---|---|
| **S1** | 单个长方体，故意遮挡全部顶点与棱（每个面只拍中间一块） | 面拟合、顶点求解、半空间筛选、定向传播、欧拉检查 | 最纯粹的骨架验证：**顶点处零观测，若能重建出 8 顶点 / 12 边，即证明「演绎优于插值」** |
| **S2** | 带孔板 + 4 个螺钉，仅从螺钉头一侧扫描 | 完全不可见面、部分缺失面、标准件匹配、配合关系、干涉回检、语义—几何冲突 | 覆盖主线全部环节；且能逼出「螺钉存在 ⟹ 板必须有孔，但点云上看不到孔」这一冲突 |
| **S3** | 含倒角/圆角/相切过渡的零件 | 边界性质判定（5.4.2 三分支判据）、退化情形兜底 | 检验 5.4.6 的 fallback 是否成立 |

**S2 是核心样本**：规模小到可以手工检查每一步，但主线每个环节都覆盖到了。实物建议直接采用标准件（如内六角圆柱头螺钉 1/4″-20 一类成熟件号），CAD 真值可从厂商库直接下载 STEP。
> 注意：厂商库多为**无螺纹简化模型**——在本框架中通常有利（螺纹属 L2 细节层，不应进入 L0 基形）。

**11.1.3 具体任务（一律最笨但可解释的实现，不引入任何学习模块）**
- **P0 预处理**：按位姿融合多视角；按入射角剔除掠射点；kNN 距离异常检测剔除 ghost point；标记边缘点（不用它拟合）。
- **P1/P2 拟合**：Open3D / CGAL 的 RANSAC 基元检测 + 区域生长 + 最小二乘精拟合；仅用远离边界的内部点。
- **P3 边界判定**：边界邻域点云的法向直方图，人工观察双峰/三峰/连续过渡。
- **P4 骨架**：OCCT 求交（SSI）；凸体走「先顶点后边」的干净路径（5.3）。
- **P5 补全**：纯规则——八级派生依据的前 7 条；不使用大模型。
- **P6 装配**：手工标注配合类型，或按同轴/贴合的几何判据粗分。
- **P7 验证**：OCCT 的 BRepCheck + 欧拉公式 + 渲染—比对残差图。
- **P8 输出**：导出 STEP AP242；provenance 与不确定性以外部文件（JSON）记录，不追求嵌入标准字段。

**11.1.4 验证方法**

| 验证项 | 方法 | 数据来源 |
|---|---|---|
| 几何精度 | 重建面参数 vs CAD 真值（法向夹角、位置偏差） | 厂商 STEP / 自建 CAD |
| 拓扑正确性 | 欧拉公式、BRepCheck、定向传播是否无矛盾 | OCCT |
| **接口是否够用** | **检查 P4 是否还需要回查点云或网格** | 手工记录 |
| 补全可靠性 | 对比补出的面与真值面的偏差，按 provenance 分级统计 | CAD 真值 |
| 失效定位 | 每一步记录失败样例与直接原因 | 手工记录 |

> 第三项最关键：**若 P4 需要回查点云或网格才能完成构造，即说明 P2 → P4 的接口定义不完整。**

**11.1.5 通过标准**
- **S1**：顶点与棱全部零观测的条件下，重建出 **8 顶点 / 12 边 / 6 面**，且 BRepCheck 判定为合法实体。
- **S2**：输出**水密装配体**；板的孔被正确推出；「螺钉—孔」冲突被 **L4 检出**并标记为待明确项。
- **S3**：倒角/圆角/相切三类**至少能正确区分前两类**（相切允许失败，但须被识别为「相切」而非误判为锐边）。
- **接口规格冻结**：P2 → P4 的数据结构定稿，且**不依赖网格**。

**11.1.6 实验预期（诚实版）**

| 项 | 预期 | 说明 |
|---|---|---|
| S1 成功率 | 较高（乐观预期 >80%） | 凸体、解析面、约束充分，属最有利情形 |
| S2 成功率 | 中等 | 「板有孔」推断是真正考验；螺钉长度仍不可判定，预期输出**候选集**而非单值 |
| S3 成功率 | 较低 | 相切过渡本质 ill-defined（9.1），允许失败但须被正确识别 |
| **最先崩在哪里** | **OCCT 的退化情形** | 判断最先出问题的是内核在某类退化输入下崩溃或产出非流形，而非任何理论难点 |
| 意外收获的可能性 | 存在 | 实际崩掉的位置往往是事先未预料到的；这恰是 V1 的核心价值 |

### 11.2 V2：学习式感知

**11.2.1 目标**：用学习模型替换 V1 中的手工规则与人工阈值，解决 V1 暴露出的鲁棒性问题。**V2 只替换感知层（P1—P3），不动构造层（P4、P7）。**

**11.2.2 前置条件（V2 不应在 V1 完成前启动）**
1. V1 定义的**接口规格**就是 V2 模型的输出格式——接口未定则训练目标不明。
2. V1 的**失败案例集**决定 V2 的数据配比与增广策略。
3. V1 给出的**「哪些错误可接受」**决定 V2 的标注口径（5.9）。

**11.2.3 具体任务**

| 阶段 | V1 实现 | V2 实现 | 替换的收益 |
|---|---|---|---|
| P1 面片感知 | RANSAC + 区域生长 + 手工阈值 | 稀疏卷积 / Point Transformer（PTv3 一类），逐点预测类型/参数/置信度 | 避开手工阈值（0.1 记录的死结）；对噪声与密度变化鲁棒 |
| P2 类型判定 | 人工设定残差阈值 | 学习式类型先验 + 解析拟合 | 类型判定更稳，且保留解析拟合精度 |
| P3 边界判定 | 人工观察法向直方图 | 法向分布特征 + 小分类器 | 三分支判据自动化（5.4.2） |

> **V2 仍遵守 2.4 核心原则：模型只输出「决策」（类型、分割、边界性质），几何参数一律由解析拟合算出。不得让网络直接回归几何坐标。**

**11.2.4 数据与训练**
- 数据来源：以工业模型库为主（1.3、第八章），合成扫描生成点云。
- 标注：全部自动生成——可见性标签、逐面类型、邻接、provenance（8.4）。
- **必须叠加真实缺失**：边缘丢失、反光空洞、密度不均。**此项不是可选项**，决定 V2 能否泛化到真实数据（10.7）。
- 起步规模：约 **1 万装配体 × 10 视角 ≈ 10 万帧**。
- 配置：8 × A100，P1 约 2–5 天；P2 / P3 单卡 <1 天。

**11.2.5 验证方法（必须做同分布 / 跨分布两组）**

| 评测 | 数据 | 衡量什么 |
|---|---|---|
| 同分布测试 | 合成数据留出集 | 模型的基本能力上限 |
| **跨分布测试** | **V1 采集的真实点云** | **sim-to-real 泛化能力（真正的考验）** |
| **端到端对比** | V1 流水线 vs V2 流水线，**同一批真实样本** | 学习式感知是否真的优于手工规则；提升在哪些环节 |
| 失败案例对照 | V1 记录的失败案例集 | V1 的失败是否被 V2 解决 |

> 第三项最重要：**V2 必须在完整流水线上与 V1 对比，而非只比较分割 mIoU**——分割指标的提升未必带来最终 B-rep 有效性的提升，二者之间隔着 P4 的符号构造。

**11.2.6 通过标准与预期**

| 项 | 标准/预期 |
|---|---|
| 通过标准 | 在 V1 的真实失败案例上，**端到端 B-rep 有效性有可测量的提升**；且跨分布退化幅度可接受 |
| 几何精度预期 | **不会显著提升**——几何由解析拟合决定，感知改进主要提升鲁棒性 |
| 拓扑有效性预期 | **应有提升**，这是 V2 的主要价值 |
| 可能的负面结果 | 分割指标提升但端到端有效性未提升 → **说明瓶颈不在感知层，应转向 P4/P5 而非继续加大模型** |

### 11.3 V3：语义与提议

**11.3.1 目标**：补上语义层与欠定情形下的候选生成能力，使系统从「能处理证据充分的部件」扩展到「能正确处理证据不足的部件」。

**11.3.2 具体任务**

| 任务 | 对应阶段/入口 | 内容 |
|---|---|---|
| 配合类型识别 | P6 | 部件图上的 GNN / 小 Transformer，识别配合类型；由类型导出剩余自由度（4.3） |
| 功能语义 | 入口 **C**（P7） | 建立部件功能语义来源（现成本体 vs 大模型常识，见 9.2）；支撑 L4 语义—几何一致性检查 |
| 欠定候选生成 | 入口 **A**（P5） | 自由度记账判定欠定时，由大模型提议标准件规格/结构假设，符号端验证一致性 |
| 骨架提议 | 入口 **B**（P5） | 面集无法闭合时，由大模型提议候选拓扑/CAD 程序，符号端验证能否闭合成水密实体 |
| 先验偏置 | 入口 **D**（P3/P6） | 分类歧义时提供领域偏置，由拟合残差与约束一致性裁决 |

> **V3 引入的大模型全部是「提议者」，输出必须经符号验证器检验（2.6）。任何一个入口都不得直接产出最终几何。**

**11.3.3 验证方法（重心不是整体成功率，而是「提议—验证」闭环是否成立）**

| 验证项 | 方法 |
|---|---|
| 提议的召回率 | 在已知欠定的样本上，正确假设是否出现在候选集中 |
| **验证器的拦截率** | **错误假设被符号端拒绝的比例（此项最关键）** |
| 候选集规模 | 平均候选数量——过大则失去消歧意义 |
| 主动消歧增益 | 经「补拍 → 重算」后，候选集是否收敛（7.1） |
| L4 检出率 | 语义—几何冲突能否被自动发现（第 6 章） |

> 「验证器的拦截率」是最重要的**安全指标**：若大模型提出错误假设而符号端未能拦下，则机制会让系统产出「看似自洽、实则虚构」的结果——那正是 5.14 要排除的失效模式。

**11.3.4 通过标准与预期**
- 通过标准：① 欠定样本上正确假设出现在候选集中的比例可接受；② **错误假设被验证器拦截的比例足够高（安全底线）**；③ 候选集规模可控，经主动消歧后能收敛。
- 预期困难：**配合类型识别本身即困难**——已有工作的关节匹配准确率在最好的类别上亦仅约 **51.4%**。
- 预期收益：L4 语义—几何检查是唯一能自动发现待明确项的机制，其价值**不随成功率线性增长**——即使在部分样本上生效，也能显著降低「静默错误」的比例。

### 11.4 三版对照总表

| | V1 验证路线 | V2 学习式感知 | V3 语义与提议 |
|---|---|---|---|
| 目标 | 证明链路可走通，定位崩溃点 | 替换手工规则，提升鲁棒性 | 补齐语义与欠定处理能力 |
| 是否训练 | 否 | 是（P1—P3） | 是（P6 + 大模型候选） |
| 改动范围 | 全链路（最笨实现） | 仅感知层 | 语义层 + P5 候选 |
| 关键产出 | 接口规格、失败案例集、「哪些错误可接受」的真值 | 学习式感知模型、泛化能力评估 | 语义来源、提议—验证闭环 |
| 投入估算 | 1–2 人月 | 数据 1–2 月 + 训练 1 周 | 后续 |
| 主要风险 | **OCCT 退化情形崩溃** | **sim-to-real 退化** | **验证器拦截率不足** |
| 失败时处置 | 重新审视路线可行性 | **转向 P4/P5，而非加大模型** | 收窄至仅用入口 C（语义检查） |

### 11.5 执行要点
- **不要跳过 V1。** 它是唯一能同时给出接口规格、失败案例与标注口径的环节；跳过它直接训练，等于**在没有真值定义的情况下定义学习目标**。
- **每版都要保留失败案例集，并且跨版本累积。** 它是唯一能判断「改进是否真的有效」的依据。
- **端到端评测优先于模块指标。** 分割 mIoU 的提升未必带来 B-rep 有效性提升；唯一有意义的对比是在完整流水线上、同一批真实样本上做。

## 本卷要点速记

1. 不确定性三级：候选集 → **主动消歧（补拍）** → 人类介入；大部分「不可判定」其实是「采集方案不够好」。
2. 数据不再是瓶颈：模型库（TraceParts 2.9 亿件号 / GrabCAD 700 万 / McMaster 70 万带 API）、Fusion360 Gallery Assembly（8,251 装配体 / 逐面标签）、HELIOS++ 合成扫描、BIMNet 评测。
3. **provenance 标签可自动生成**（CAD + 位姿 → 可见性真值）；**as-designed 正是 L0 的正确训练目标**。
4. 两个 gap：as-designed vs as-built domain gap；理论可见性 vs 真实可采的 sim-to-real gap（须叠加真实缺失）。
5. 缺口优先级：**拓扑骨架搜索策略** > 几何内核鲁棒性 > as-built 变异 > 评测协议 > 标准件库 > 功能语义。
6. 风险：过度规整化（掰直磨损，最隐蔽）；相切退化；数据缺口；水密率上限约七成。
7. 骨架很轻：主干 **< 100M 参数**（P1 最重 30–60M）；数据 1–10 万装配体、每零件 4k–10k 点；数据生成 3–10 天可能比训练更慢。
8. 三版路线：**V1（1–2 人月、不训练、全链路最笨实现）→ V2（学习式 P1–P3）→ V3（语义 + 提议）**。
9. V1 三级样本 S1 长方体（顶点零观测）/ S2 带孔板+螺钉（核心）/ S3 倒角圆角相切。
10. V1 三项产出：接口规格、失败案例集、「哪些错误可接受」的真值。预期最先崩在 **OCCT 退化情形**。
11. V3 最关键指标 = **验证器拦截率**（安全底线）；配合类型识别准确率仅约 51.4%。
