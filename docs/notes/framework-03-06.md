## 第 3 章　缺失的分类与处理

### 3.1 三类面（核心分野在「部分缺失」一行）

| 面类型 | 传统方法 | 深度学习 | 大模型 | **建议策略** |
|---|---|---|---|---|
| 完整面 | 直接拟合，精确 | 同 | 同 | 无争议 |
| **部分缺失面**（遮挡/高反光空洞） | 解析延拓，**0 自由度、精确（演绎）** | 生成式补全，合理但不确定（归纳） | 程序外推，精确但受表达力限 | **优先传统**；仅当类型识别失败时才用学习式 |
| **完全不可见面**（装配结构导致） | 约束推理（支撑/对称/标准件） | 先验采样，多种可能 | 候选假设生成 | **输出候选集 + 置信度，不作单一断言** |

关键认识论区分：**解析延拓 = 演绎（确定答案）；生成式补全 = 归纳（合理猜测）**。在人造物场景下前者适用面远大于通常认知——**曲面类型一旦被识别，缺失部分由方程唯一确定，与缺失面积无关**。

### 3.2 未见/不全面面的派生依据分级（八级）

每个派生面必须带 **provenance 标签**（已确立），用于冲突时的调整次序与输出可信度。

| 序 | 依据 | 例子 | 自由度 | 级别 |
|---|---|---|---|---|
| 1 | 面内解析延拓 | 曲面中间有孔洞 | 0 | 已确立 |
| 2 | 邻接面求交截断 | A 沿自身几何延展，到 B 面停下 | 0 | 已确立 |
| 3 | 厚度读取 → 生成背面 | 由窄环带宽度得厚度 → 生成内表面 | 0（给定厚度） | 合理推论 |
| 4 | 配合约束 | A 的背面 = B 的贴合面 | 由 mate 类型定 | 已确立 |
| 5 | 支撑/接触物理约束 | 盒子底面 = 桌面所在平面 | 部分 | 合理推论 |
| 6 | 对称/重复结构 | 四条相同支腿、阵列孔 | 0（若对称判据成立） | 合理推论 |
| 7 | 标准件/模板匹配 | 螺栓、型钢 | 0（给定规格） | 已确立 |
| 8 | 纯先验假设（兜底） | 无任何线索 | 欠定，必须标注 | 已确立 |

**硬规则（已确立，反复出现）**：基元只用**远离边缘的内部点**拟合；边由**曲面—曲面求交（SSI）**导出，绝不从边缘点测量。

三条推论：
1. **边的精度高于其来源数据**——边由两个经大量干净点拟合的曲面求交得到，噪声被平均掉。
2. **可在完全没有点的地方生成边**（被遮挡的角落、背面交线）。锐利不是后处理磨出来的，是表示的副产物。
3. **应主动剔除边缘附近的点**——mixed pixel / ghost point 高发区，实践中常按入射角过滤。

> 独有优势：相机在机械臂上且位姿已知，可主动规划视角使关键表面接近**法线观测**，从源头消除掠射伪影（合理推论）。

### 3.3 部件级缺失：一类特殊的不可判定

**完全不可见 ≠ 一类问题**，须分两种（已确立，本轮研讨的关键区分）：

| 维度 | 空盒子内部 | 螺钉凸起 |
|---|---|---|
| 观测状态 | 完全不可见 | 部分可见（凸起可见，杆部不可见） |
| 类型线索 | 无 | 有（可识别为标准件） |
| 可判定性 | **根本不可判定** | 参数不可判定，但**结构关系可判定** |
| 处理 | 不做任何假设 | 提出待明确项，交人类选择 |

空盒子情形的澄清（已确立）——须分离两件事：
- **拓扑闭合性可判定**：外表面点云闭合即为闭合，必须闭合，否则不是合法 B-rep；
- **内部是否为空腔不可判定**：不假设，仅标注。
- 关键认知：**B-rep 的「实心」是拓扑概念，不是物理概念**。封闭纸箱的外表面构成完全合法的实心 B-rep。
- 工程后果：质量属性（质量、重心、转动惯量）会全错，而它们恰是机器人抓取与仿真所需 → **空腔不可判定时，质量属性须标记为不可信**。

## 第 4 章　约束系统与联合求解

### 4.1 为什么必须联合求解

**一个部件的未见面，往往恰好是另一个部件的可见面。** 贴合的两法兰：A 的背面不可见，B 的正面也不可见——但它们是同一个接触面 → **循环依赖**，逐部件独立求解会把该循环切断，两边都只能猜。

反过来：**遮挡是互补的**。联合求解使信息双向流动。工程先例（已确立）：以模拟退火将参数化 CAD 模型拟合到装配体点云，优化变量可含装配约束，多部件同时拟合，由 CAD 内核维护约束一致性。

### 4.2 约束系统的构成

| 类别 | 内容 | 来源 | 级别 |
|---|---|---|---|
| 点云观测 | 点—面距离、法向一致性 | 传感器 | 已确立 |
| 几何约束 | 共面、垂直、相切、共轴、对称、倒角 | 面—边—顶点图推理 | 已确立 |
| 物理/装配约束 | 支撑、接触、遮挡、装配关系、运动副 | 场景与配合推理 | 合理推论 |

物理约束值得单独强调：**物体置于桌面这一物理事实，直接给出完整一个面的几何**（底面必与桌面共面或贴合、必具支撑关系、与四侧面成确定夹角）。这不是几何猜测，而是**定解条件**——纯视觉方法完全无法利用「接触」这一概念。

### 4.3 配合类型决定剩余自由度

AutoMate / SB-GCN 把配合建模为「一对配合坐标系（MCF）+ 约束类型」，共 8 类。其对框架的意义：**mate 类型直接给出剩余自由度**，从而决定未见面被约束到什么程度（已确立）。

| Mate 类型 | 剩余 DOF | 未见面的确定程度 |
|---|---|---|
| fastened（紧固） | 0 | 完全确定 |
| planar（平面贴合） | 2 平移 + 1 旋转 | 部分确定 |
| revolute（铰链） | 1 旋转 | 沿轴确定，绕轴不确定 |
| cylindrical（柱面） | 2 | 部分确定 |

⚠️ 反证：纯几何推理不足以确定部件间关系——多部件装配研究表明，仅用全局几何的方法会忽略部件的旋转/反射对称性，导致**上下颠倒与翻转**；单纯加入 joint loss 会引发**部件塌缩（collapse trap）**。→ 配合/接触信息不可或缺（已确立）。

### 4.4 自由度记账：防编造的质量闸门

| 自由度状态 | 处理 | 输出标记 |
|---|---|---|
| 0（完全被约束确定） | 直接闭合 | 可信 |
| 有限（需少量假设） | 闭合并记录假设 | 记录假设内容 |
| **欠定（约束数 < 未知量数）** | **不闭合** | **开放边界 + 标注** |

第三行是防止「编造结构」的**最后闸门**。宁可输出带开放边界标注的模型，也不要输出一个自洽但虚构的模型——后者正是「肿瘤块」，只是换了一件外衣。

### 4.5 干涉回检的两个前提（合理推论）

1. **先做接触类型分类，再判干涉**——过盈配合、螺纹连接、焊接在模型上表现为**真实互穿，却是正确结果**。朴素的「消除穿透」会把它们全部改错。判据不是「有没有重叠」，而是「实际关系是否落在该连接类型允许的区间内」。
2. **双向检查**——不该碰的碰了（干涉）是错，该碰的没碰（漂浮、悬空）**同样是错**。

调整次序遵循 provenance：**优先改 assumed，其次 inferred，最后才动 observed**。实测是证据，推断是假设；冲突时改假设不改证据（否则误差在部件间来回传递，越调越乱）。

## 第 5 章　骨架构造与定向（本框架的技术核心章）

本章回答两个此前悬置的问题：**骨架从何而来、定向如何确定**，并给出「本框架不会产出肿瘤块」的根本论证。
结论：**定向基本不是问题，骨架可从解析面计算得出，真正难点已坍缩为「面集是否完整」**；该难点在本框架下不追求完美，改由分级输出与标注承载。

### 5.1 骨架是什么：B-rep = 几何 + 拓扑

骨架即面—边—顶点的连接关系，不含具体几何。立方体：6 面 / 12 边 / 8 顶点，每条边恰被两个面共享——**这个结构本身就是水密性**。

- 若每个面各自算自己的边界，A 面算一条、B 面算一条，位置差 0.05 mm 即**微缝**，水密失败；
- 骨架规定「二者共享同一条边实例」，则该问题**在构造上就不存在**。
- → **水密性是骨架的性质，而非几何的性质**。这就是「水密须由构造保证、不能靠修复保证」的含义。

| | 面集合（face soup） | B-rep 实体（solid） |
|---|---|---|
| 构成 | 若干裁剪面拼在一起 | 面 + 边 + 顶点 + 关联 + 定向 |
| 体积/质量属性 | 无 | 有 |
| 布尔运算 | 不可 | 可 |
| STEP 实体类型 | ManifoldSurfaceShapeRepresentation / GeometricallyBoundedSurface（**明列为 non-solid**） | ManifoldSolidBrep（要求 closed shell） |
| 本质 | 不是「一个不太好的实体」 | 而是**「根本不是实体」** |

### 5.2 局部骨架的五个要素

以一个顶点处三个面两两相交为例：

| # | 要素 | 能否由几何算出 | 说明 |
|---|---|---|---|
| 1 | 顶点位置 | 能 | 由三个面方程联立解出（5.3） |
| 2 | 边（作为曲线） | 能 | 面—面求交（SSI） |
| 3 | 关联关系（边属于哪两个面） | 能 | 边同时落在两个面内，可反推 |
| 4 | 定向（面法向、边方向） | 不能（是选择） | 但可由观测**唯一确定**，见 5.5 |
| 5 | 顶点扇形序（closed fan） | 不能（是选择） | 决定面的边界回路走向；凸角处可由面法向导出 |

### 5.3 构造顺序：先顶点，后边

常见写法「先求三条交线，再求其交点」应更正：三个平面两两求交得三条直线，数值上**并不共点**，而是围成一个小三角形（浮点精度决定，无法避免）。

- **顶点**由三个面方程联立解出：三方程三未知数，**精确解，不引入容差环节**。
- 筛选候选顶点：对凸体，真顶点必须落在其余所有面的正确一侧（**半空间检验**）。6 个面取 C(6,3)=20 个三元组，筛余 8 个。
- **边**由顶点对定义：每条边 = 共享两个面的那个顶点对，得 12 条边。

收益是实质性的：边由两个端点定义，**两端天然一致**，不会出现「这侧算一条线、那侧算一条线、中间接不上」——**水密性在该构造中是免费的**。
- 局限：半空间检验仅对**凸体**成立。非凸、含贯通孔、含裁剪曲面时，须回到「交线 + trim 裁剪 + 顶点合并」的一般路径，并引入顶点容差。
- 与容差分离原则相容：**用大容差合并顶点（保证闭合），用精确值存面参数（保证几何）**。

### 5.4 网格与点云的分工：面内用网格，边界用点云 ⭐

#### 5.4.1 三角化的价值仅在面内
「点云 → 三角化 → 拟合 NURBS」在边界处是**南辕北辙**：三角化把连续曲面有损离散为分片线性，拟合又要从分片线性恢复连续。面内部有益（稠密、均匀、带法向的采样），边界处则引入**拓扑噪声**（三角形的连接方式本身带任意性）。
→ **分工原则：三角化只用于面内，不用于边界；边界信息一律回原始点云取用。**

#### 5.4.2 关键洞察：网格在交界处圆化，点云反而锐利

| | 三角网格 | 原始点云 |
|---|---|---|
| 交界处表现 | 系统性圆化 | 有噪声，但保留分布信息 |
| 能否区分 R0 锐边与 R2 倒角 | **不能**（圆化后形态一致） | **能** |
| 信息是否可恢复 | 已永久丢失 | 可统计判别 |

判据 = **边界邻域点云法向的统计分布**，三分支形态不同且可区分：

| 交界性质 | 法向分布特征 | 处理 |
|---|---|---|
| 锐边（直接贯穿） | **双峰**，两峰间无中间态 | 两解析面求交，得精确锐边 |
| 倒角 | 存在**第三组中间法向**的点，且可拟合成小面 | 拟合第三组点为小面，加入面集 |
| 圆角 | 法向**连续过渡**（自 A 渐变至 B） | 按倒角处理，并**标注为圆角** |
| 相切 | 无真实棱边 | 改用约束拟合（见 9.1） |

重要性：直接补上 5.8「唯一真难点」中最危险的一类错误——**漏掉倒角、两个大面被误当作直接相接**。网格一旦圆化，该三分支判据即坍缩为一种，信息永久丢失。

#### 5.4.3 判定与定位必须分离

| 任务 | 数据来源 | 理由 |
|---|---|---|
| **判定边界性质**（锐边/倒角/圆角/相切） | 边界邻域**点云** | 网格已丢该信息；点云保留法向分布 |
| **确定边界位置**（这条边在哪） | 解析面**求交（SSI）** | 点云边缘位置不可靠：mixed pixel / ghost point 可使测距落在前景、背景、中间，甚至比前景更近或比背景更远 |

> 点云在边缘处「更锐利」是指**结构信息更丰富**，不等于位置更准确——恰恰相反，其位置是全数据中最脏的一批。→ **判定用点云，定位用几何。**

#### 5.4.4 修正后的边界处理流程
1. 用面内点（远离边界）拟合两个面的解析式 ← 网格或点云均可
2. 用边界邻域点云做法向直方图，判定：锐边 / 倒角 / 圆角 / 相切 ← **判定：用点云**
3. 锐边 → 两解析面求交，得精确锐边 ← **定位：用几何**
4. 倒角 → 拟合第三组点为小面，加入面集
5. 圆角 → 按倒角处理，并标注为圆角
6. 相切 → 无真实棱边，改用约束拟合（9.1）

#### 5.4.5 与常规管线的结构性差异

| | 常规管线 | 本框架 |
|---|---|---|
| 顺序 | 点云 → 网格 → 分割 → 拟合 → 求交 | **面内拟合 → 边界判定 → 求交** |
| 区域划分依据 | 取自网格的分割边界 | 取自**解析面的交** |
| 交界处信息 | 已被三角化圆化，不可恢复 | 由点云保留，可判定 |
| 失效点 | 分割建立其上，后续步骤全被污染 | 边界**从不经过网格这一层** |

→ 应作为独立原则固定：**边界信息不经过网格离散化这一层。**

#### 5.4.6 退化情形与兜底
失效情形：① 边缘点密度过低（深孔、背面交界）；② 倒角尺寸接近噪声水平（σ=0.1 mm 时 R0.5 可分辨、R0.2 无法区分）；③ 三个以上曲面交汇的顶点附近（法向混杂，分支不可分）。
→ 应 **fallback 到默认假设（按锐边处理）并标注不确定**，而非强行判定（与 5.12、第 7 章一致）。

### 5.5 定向：基本不是问题

5.2 中第 4、5 项曾判为「不是算出来的，而是选出来的」——**该判断需修正**：定向可由观测唯一确定，选择空间极小。

B-rep 约定本身即：**面的正面 = 从实体外部观看时可见的那一侧**。「能看见」与「法向朝向观察者」是同一件事的两种表述。物理原因：只能从没有材料的那一侧看到表面。空腔情形同样成立（扫描盒子内部时法向朝空腔，与 B-rep 中 void shell 的定向约定一致）。

定向自由度坍缩为：
- **每个可见面的法向**：由相机位姿直接确定，无需推断。
- **全局内外**：封闭壳只有两种一致定向（全朝外/全朝内），只要存在一个可见面，这 1 个比特即被锁死；其余由 BFS 沿共享边传播。
- **边方向**：由面法向 + 右手定则导出，非独立自由度。
- **顶点扇形序**：凸角处由三个面法向的球面三角关系导出；非凸处需实际求交确定。

两点补充：① 传播若矛盾，即为**非流形**的真实信号，而非「选择失败」；② 全局法向定向在点云处理中是公认难题（多需 MST 或定向传播），本场景因**相机位姿已知**而天然获得——**硬件配置带来的、此前被低估的优势**。

### 5.6 B-rep 有效性条件（实现清单）

| 类别 | 条件 |
|---|---|
| 拓扑 | 每个面至少 3 条边；每条边恰好 2 个顶点；每条边最多属于 2 个面；顶点周围的面构成闭合扇形（closed fan） |
| 几何 | 顶点坐标互异；边要么不相交、要么交于公共顶点；**面要么不相交、要么交于公共边或顶点**；同一条边的两条边界曲线必须重合；曲面不自交 |
| 定向 | 满足 Möbius 规则，内外可区分；外环自外侧看逆时针、内环（孔）顺时针；同一条边在两个面中遍历方向相反 |

「面只能交于公共边或顶点」一条，解释了**「两个大面之间偷偷夹了一道未被识别的倒角」为何直接判死**：两个面在不属于公共边的位置相交了。

Requicha（1980）早已指出：B-rep 有效性检查在计算上并不划算；绝大多数几何系统把有效性条件**嵌入构造算法**，而非事后检验。→ 与本框架主张一致：**有效性是构造出来的，不是检查出来的。**

### 5.7 欧拉—庞加莱检查的定位

公式：**V − E + F = 2(S − G) + R**（S = shell 数，G = 贯通孔数，R = 面内环数）。立方体：8 − 12 + 6 = 2 ✓。

定位：**不是查定向的（定向已由 5.5 解决），而是查「面数对不对」的**。少一个面：8 − 12 + 5 = 1 ✗，立即捕获 → 针对「面集完整性」这一唯一真难点的**廉价探测器**。
- 必要非充分：无法检出非流形边、自交、法向翻转、微缝。
- 例：两个内部重叠的立方体并为一个壳，计数与单立方体相同、公式成立，但并非合法实体。

### 5.8 问题坍缩：唯一真难点是面集完整性 ⭐

| 曾以为的难点 | 实际状态 | 依据 |
|---|---|---|
| 定向、边方向、顶点扇形序 | **已解决** | 可见性 + 1 个全局比特（5.5） |
| 骨架「从哪来」 | 降级为计算 + 少量选择 | 解析面求交/联立（5.3）；剩余选择仅「哪些面对需求交」「交线的哪一段是真边界」 |
| **面集是否完整** | **唯一真难点** | 八级派生依据 + 自由度记账（3.2、4.4） |
| 判定「哪些错误可接受」 | 新增，且依赖功能语义 | 见 5.9 |

面集两类错误后果截然不同：
- **少一个面**：壳闭不上，欧拉公式立即报警——易发现。
- **多一个（或错一个）面**：如漏掉倒角、两个大面被当作直接相接——能闭合、能水密、看起来合理，但**结构是错的**——危险。须由**残差回检**发现，拓扑层无法解决。

### 5.9 可构建性优先于保真度

两类错误代价不对称且悬殊：漏掉 R2 倒角 → 几何偏差约 2 mm，局部；建不出 B-rep → 一无所获，代价无穷大。

**原则：可构建性优先于保真度；保真度由标注承载，不由几何承载。** 按「理想化可逆」原则，被抑制的特征并非删除，而是移置补充层并标注 → 「结构错一点」不是永久损失。

限定（工业界 defeaturing 成熟规则：**按功能分级，而非按尺寸分级**）：
- **可抑制**：倒角、圆角、小孔、螺纹、毛刺等非承重特征。
- **绝不可抑制**：配合面、密封面、定位面。

实例：漏掉 R2 圆角 → 偏差 2 mm 但不影响装配关系，可接受；漏掉一个螺栓孔 → 几何偏差同样几毫米，但**整个连接关系消失**，下游装配验证与干涉检查全部失效，不可接受。二者尺寸相当，**后果差着量级**。
→ 这正是功能语义层（第 7 章）的关键价值之一：**判定「哪些错误可以接受」的依据**。没有它，无法区分「漏了个圆角」与「漏了个螺孔」。

### 5.10 光滑性强制：整体平整优先于局部保真

要求是「面整体平整、不得凹凸不平」，**不等于处处二阶微分连续**：
- **不要求** C² 连续——分片光滑曲面在片间以棱（crease）相接，完全合法（1.1 判据二）。
- **要求** 单个曲面片内部整体平整——曲率可变化（柱面、锥面、回转面），但不得出现非设计意图的局部凹凸起伏。

处理规则：点云在某面上呈小尺度凹凸，若不能被判定为可确定、可重构的小结构，则一律不作为几何保留，依四周区域**重新生成并填补**。

两条依据：① 小凹凸成因绝大多数是噪声或细节（刀痕、磨损、锈蚀、点云噪声、配准残差）→ 属 L2 细节层而非 L0 基形；② 若为真实结构，应能被独立重构（真实小结构有可识别边界与解析形式）——凡不能被捕获者，按定义即无法确定地重构，保留它只会得到虚构几何。

| 情形 | 判定 | 处理 |
|---|---|---|
| 起伏具备可识别边界与解析形式 | 真实小结构 | 作为独立特征重建（凸台/孔/筋等） |
| 起伏无明确边界、尺度接近噪声水平 | 噪声/细节 | 归入 L2；L0 面按四周区域重新生成填补 |
| 起伏明显但无法判定归属 | 不确定 | 按四周填补 L0，并**提示该处存在未解释的起伏** |

第三条尤其重要：**填补不等于否认**——几何按平整处理，标注中保留「此处实测存在未被解释的起伏」这一事实。

### 5.11 面上的附着物：基底完整优先

| 对象 | 优先级 | 错误后果 | 处理策略 |
|---|---|---|---|
| **基底面/基底实体** | 高 | 污染整个面与实体，破坏面集完整性，可能导致无法闭合 | 按四周区域**解析延拓**，优先保证完整与平整 |
| 附着物 | 低 | 局部、附加、可后期删除或替换 | 能识别则重建；不能确定则**随意构造 + 提示 + 可选项** |

取舍逻辑：两者代价不对称。附着物不确定时，须在结果中明确提示，并列为可选项——下游可选择保留、删除或替换为更合理假设。

### 5.12 不可闭合也不丢弃：四档输出

| 档 | 状态 | 输出 |
|---|---|---|
| 1 | 面集完整、全部有据 | 水密 B-rep，标注可信 |
| 2 | 可闭合，但含理想化/假设面 | 水密 B-rep + 理想化标注（结构可能简化） |
| 3 | **无法闭合** | **不丢弃**：输出开放壳 + 标注「未闭合」 |
| 4 | 几乎无线索 | 不重建，仅记录空间占位 |

第 3 档最关键：部件间遮挡是**互补**的（4.1），未闭合部件仍为邻居提供约束。其已拟合好的面依然可信，依然能约束相邻部件的位姿与未见面；若整个丢弃，这份约束信息随之消失，**邻居的重建质量连带下降**。

### 5.13 自由度记账与残差回检：各管一半

| 机制 | 管什么 | 抓不住什么 |
|---|---|---|
| 自由度记账（4.4） | **能不能定**：约束数 < 未知量数 → 欠定 → 不闭合 | 抓不住「**错误定**」 |
| 残差回检 | **定得对不对**：结果渲染回输入视角比对，残差系统性偏高 → 该处是结构而非细节 | 依赖阈值与视角覆盖 |

「错误定」典型情形：某面依对称性补全，自由度为 0、置信度满格，但若对称性假设本身错误（那条腿本不对称），则得到一个**自由度为零、看似完全确定、实则错误**的面。此类错误**只能由残差回检发现**。两者缺一不可。

### 5.14 为什么本框架不会产出「肿瘤块」

理由不是「模型更准」，而是**机制不同**：
- **补全的依据是演绎而非插值**：面集由解析延拓、邻接求交、配合约束、支撑接触、对称性、标准件等依据派生（3.2），而非从形状分布中采样。
- **无法构造的不强行补**：几何/功能/物理任一约束都构造不出面，则不补，保留已确定部分并标注。
- **欠定即停止**：自由度记账判定约束不足时，输出开放边界而非强行闭合（4.4）。
- **不确定性显式化**：不可判定项输出候选集而非单一断言，交由主动消歧或人类介入（7.1）。

→ 「肿瘤块」的成因（在缺乏约束处强行给出一个确定但虚构的结构）在本框架中没有立足之地。**宁可给一个「标了注的 90%」，也不给一个「假装 100%」。**

## 第 6 章　语义层与双向验证

### 6.1 三类语义的定义

| 语义 | 回答什么 | 例子（螺钉） | 来源 |
|---|---|---|---|
| 几何语义 | 形状本身可推出什么 | 圆柱 + 螺旋结构 + 头部形式 | 曲面类型、参数、拓扑邻接 |
| 功能语义 | 它干什么用 | 必须穿过被连接件、需预紧 | 部件分类 → 常识/知识库 |
| 物理语义 | 它如何受力、如何运动 | 轴向预紧力、配合公差、可拆卸性 | 功能语义 + 材料/工况 |

### 6.2 两级分类
建议顺序：**先对对象整体分类，再对部件分类**（假设）。对象分类提供上下文，使部件分类更准确；部件分类正确后，功能语义方可附加。
- 输入不止形状——点云带颜色时，**几何 + 颜色**可显著改善部件分类（合理推论）。
- **粗分类在前、精分类在后、可回溯**：早期粗分类（「大概是个标准件」）立即提供强约束（直径已知）；晚期精分类（「M8×20 还是 ×25」）触发修正。

### 6.3 双向验证：几何 ↔ 语义

| 方向 | 路径 | 作用 |
|---|---|---|
| **正向（由形推用）** | 几何语义 → 部件分类 → 功能语义 → 物理语义 | 为部件附加约束，扩大约束系统，减少未知量 |
| **反向（由用校形）** | 功能/物理语义 → 约束 → 修正几何 | 发现几何中不可能或不自洽之处 |

反向验证是本框架**独有能力**：传统 CAD 重建没有语义层，故不存在这一检查。典型例子——**螺钉悬在完整无孔的桌板上**：几何说桌板完整，语义说螺钉必须穿过某物。冲突出现即意味着某处不确定。
→ 这意味着**无需额外训练不确定性检测器**：语义知识与几何模型的一致性检查天然就是探测器。建议设为独立的第四级检查（合理推论）：

| 层级 | 检查内容 | 发现冲突意味着 |
|---|---|---|
| L1 部件级 | 实体是否合法水密（流形、无自交、无微缝） | 单个部件没做对 |
| L2 配对级 | 接触关系是否落在允许区间 | 接触类型判错或尺寸错 |
| L3 全局级 | 整体装配有无非预期干涉/漂浮 | 装配位姿错或累积误差 |
| L4 语义—几何级 | 已识别部件的功能语义是否与几何一致 | 存在待明确项，需人类介入 |

### 6.4 非单调推理：语义反过来改几何

螺钉案例完整时序：阶段 1 未识别类型 → 桌板建成完整无孔；阶段 2 识别出螺钉 → 触发「必须顶入桌面」→ 桌板需要开孔。**后一步结论回溯推翻了前一步结论**——传统几何管线是单向的（感知→几何→语义），语义只能往上贴，不能反过来改几何。本框架必须支持**非单调推理**。

实现机制（合理推论）：真值维护系统（**TMS**）——每个面、每个实体除 provenance 外，须记录 **dependency**（依赖哪些假设）。新部件类型被识别时，沿 dependency 找到所有受影响几何并**重算**。缺少此机制，流程会退化为「推倒重来」式全量重跑。

## 本卷要点速记

1. 缺失分三类：完整面（直接拟合）/ 部分缺失面（**优先解析延拓，演绎优于归纳**）/ 完全不可见面（约束推理 + 候选集）。
2. 八级派生依据 + provenance 标签是补全的核心工具；**基元只用内部点拟合，边一律由 SSI 求交导出**。
3. 「实心」是拓扑概念：闭合纸箱的外表面就是合法实心 B-rep；但质量属性须标为不可信。
4. 必须联合求解（遮挡互补、循环依赖）；mate 类型直接给出剩余自由度；**自由度记账**是防编造的闸门。
5. 干涉回检两前提：先分接触类型再判干涉（真实互穿可能正确）；双向查（干涉 + 漂浮）。
6. 骨架 = 拓扑；**水密性是骨架的性质**；先顶点后边 → 水密免费；欧拉公式 V−E+F=2(S−G)+R 是「面数对不对」的廉价探测器。
7. **定向基本不是问题**（可见性 + 1 个全局比特 + BFS 传播）——相机位姿已知带来的被低估优势。
8. 网格 vs 点云分工：**面内用网格，边界用点云**；**判定用点云（法向直方图三分支），定位用几何（SSI）**。
9. **唯一真难点 = 面集完整性**（多/错一个面能水密但结构错，只能靠残差回检 + 功能语义）。
10. 可构建性优先于保真度；defeature 按**功能**分级（配合面/密封面/定位面绝不可抑制）。
11. 四档输出（含「无法闭合也不丢弃」）；自由度记账管「能不能定」，残差回检管「定得对不对」。
12. 三/四级语义检查 L1–L4；反向验证（由用校形）无需额外训练不确定性检测器；**TMS 支持非单调回溯**。
